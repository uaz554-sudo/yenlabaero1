# 新航頭等艙樟宜機場專屬禮賓！從下車、報到、出境一路陪到登機門，10/28 起頭等艙貴賓室改桌邊點餐

**新聞分類：航空資訊／星空聯盟**
**發布日期：2026 年 10 月 21 日**

**新加坡航空**在樟宜機場，為**套房（Suites）與頭等艙**旅客推出**專屬禮賓服務（First Class Concierge Service）**，從抵達機場門口、報到、出境、貴賓室，到前往登機門都有人陪同；**轉機與抵達新加坡**的旅客也有禮賓協助。

貴賓室也同步升級，**10 月 28 日起**，頭等艙 SilverKris 貴賓室在原本的自助餐之外，新增**桌邊點餐服務**。

![新航頭等艙高爾夫球車接送](/assets/images/sia-concierge-buggy.jpg)

*頭等艙旅客可以搭專屬高爾夫球車前往登機門（圖片來源：新加坡航空）*

## 一、從下車到登機的流程

| 階段 | 服務內容 |
| --- | --- |
| 抵達機場 | 下車處有行李員協助行李，直接前往頭等艙報到區，報到時送上冰毛巾 |
| 報到後 | 禮賓人員陪同通過出境審查，帶到 SilverKris 貴賓室 |
| 安檢 | 樟宜第三航廈 A1～A5 登機門可走「頂級快速安檢通道」；其他登機門有專人協助安檢 |
| 前往登機門 | 視情況提供免費高爾夫球車接送 |

- **快速安檢通道時間：** 每天上午 8:30～中午 12:30、晚上 9:00～凌晨 1:00 開放，PPS Solitaire 會員也能使用。
- **適用對象：** 從新加坡出發、在新加坡轉機、抵達新加坡的新航套房與頭等艙旅客。

![新航禮賓人員陪同旅客](/assets/images/sia-concierge-service.jpg)

*禮賓人員一路陪同旅客（圖片來源：新加坡航空）*

## 二、轉機、抵達也有禮賓

- **轉機旅客：** 禮賓人員會帶領前往貴賓室，並協助接下來的轉機行程。
- **抵達新加坡：** 禮賓人員迎接旅客，陪同到行李提領處，拿完行李後協助後續交通安排。
- **搭其他航空轉新航頭等艙：** 從其他航空公司轉乘新航套房或頭等艙的旅客，也能使用禮賓服務。

## 三、貴賓室升級：10/28 起桌邊點餐

| 項目 | 內容 |
| --- | --- |
| 頭等艙 SilverKris 貴賓室 | 10/28 起新增桌邊點餐服務，自助餐照常提供 |
| The Private Room | 維持原本的個人化餐飲服務 |
| 新菜單 | 頭等艙、商務艙 SilverKris 貴賓室與 KrisFlyer 金卡貴賓室推出新的單點菜單，含兒童餐 |
| 吧台與咖啡吧 | 頭等艙、商務艙貴賓室延長為清晨 5 點到凌晨 2 點 |
| 無麩質選擇 | 頭等艙貴賓室與 The Private Room 提供無麩質麵包與甜點 |

- **最早 24 小時前就能進貴賓室：** 新航表示，旅客最早可以在航班起飛前 24 小時使用貴賓室。

## 四、對台灣旅客的影響

- **在新加坡轉機時用得到：** 台灣旅客多半是從台北飛新加坡，再轉搭有頭等艙的長程航線，才會用到這項服務。
- **轉機也能用：** 從台北飛新加坡，再轉新航頭等艙去歐洲、澳洲、美國的人，轉機時一樣有禮賓協助。
- **用哩程換頭等艙：** 新航是星空聯盟，可以用新航 KrisFlyer 哩程兌換套房與頭等艙；新航也剛公布新一代頭等艙與商務艙，可以參考我們整理的[新航新頭等艙、商務艙](/singapore-airlines-new-first-business-class-reveal)。

## 五、總結

**新加坡航空在樟宜機場為套房與頭等艙旅客推出專屬禮賓服務，從門口、報到、出境、貴賓室到登機門一路陪同，轉機與抵達新加坡也有禮賓協助；10 月 28 日起頭等艙 SilverKris 貴賓室新增桌邊點餐服務。** 台灣旅客在新加坡轉機搭新航頭等艙時，就能用到這項服務。
