# 達美 CEO：旅客不會因為 Wi-Fi 選航空公司；Delta One 基本商務艙 2027/1/19 起不能進貴賓室

**新聞分類：航空資訊／天合聯盟**
**發布日期：2026 年 11 月 19 日**

**達美航空**這週有兩則和旅客體驗有關的消息：CEO **Ed Bastian** 說旅客不會因為 Wi-Fi 選航空公司；另外，Delta One **基本商務艙（Basic Business）**明年 1 月起不能進貴賓室。

## 一、CEO：旅客不會因為 Wi-Fi 選航空公司

Bastian 在《財星》Fortune 500 Innovation Forum 被問到為什麼沒選 **Starlink**、以及和馬斯克的口水戰。

| 重點 | Bastian 的說法 |
| --- | --- |
| Starlink | 達美疫情期間曾提供飛機給 Starlink 測試，但**談不攏商業模式** |
| 選擇 | 相信除了 Starlink 會有其他低軌衛星服務，看好 **Amazon** |
| Viasat | 達美現在用 Viasat，「**不是 Starlink 等級，但非常接近**」 |
| 結論 | 「**旅客不會因為 Wi-Fi 選航空公司**」，重點是整體體驗 |

## 二、達美 Wi-Fi 現況

| 項目 | 內容 |
| --- | --- |
| 現在 | **Viasat**，SkyMiles 會員免費 |
| 未來 | **Amazon Leo**，最快 2028 年，先裝不到一半機隊 |
| 進度 | Amazon Leo 落後 Starlink，又遇到**火箭發射失敗** |
| 競爭 | 聯合航空等美國航空公司已選 Starlink |

Bastian 2023 年宣布免費 Wi-Fi 時曾說，目標是讓機上體驗「**和地面上一樣**」。外界認為 Viasat 和 Starlink 的速度仍有明顯差距。

## 三、基本商務艙 2027/1/19 起不能進貴賓室

達美 **2026 年 7 月**推出 Delta One **Basic Business**，**9 月**起的航班開始販售，是比一般 Delta One 便宜的商務艙票價。

| 項目 | Basic Business |
| --- | --- |
| 平躺座椅 | **保留** |
| Delta One 餐飲 | **保留** |
| 第 1 區登機 | **保留** |
| 選位 | 有限制 |
| 改票 | 有限制 |
| 哩程累積 | 較少 |
| **Delta One 貴賓室** | **2027/1/19 起不能進** |
| **Delta One 專屬報到** | **2027/1/19 起不能用** |

**2027 年 1 月 19 日以前**，Basic Business 旅客還能用貴賓室和專屬報到。

## 四、台灣旅客要注意

| 情況 | 建議 |
| --- | --- |
| 訂達美商務艙飛美國 | 看清楚是一般 Delta One 還是 **Basic Business** |
| 重視貴賓室 | 2027/1/19 起要買一般 Delta One |
| 只在乎平躺睡覺 | Basic Business 比較便宜，座椅一樣 |

## 五、總結

**達美 CEO 認為旅客不會因為 Wi-Fi 選航空公司，Viasat「非常接近」Starlink；Amazon Leo 最快 2028 年才上線。** 另外，Delta One 基本商務艙 **2027/1/19 起不能進 Delta One 貴賓室和專屬報到**，平躺座椅和餐飲保留，訂票時要看清楚票價種類。
