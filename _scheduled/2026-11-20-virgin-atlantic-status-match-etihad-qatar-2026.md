# 維珍航空會籍匹配新增阿提哈德、卡達，國泰馬可孛羅鑽石卡也能換 Flying Club 金卡（天合聯盟超級精英）

**新聞分類：哩程資訊／天合聯盟**
**發布日期：2026 年 11 月 20 日**

**維珍航空 Flying Club** 的會籍匹配名單 11 月 19 日新增**阿提哈德**和**卡達航空**。對台灣讀者來說，名單裡最值得注意的是**國泰航空**：馬可孛羅會**鑽石卡**可以換到 Flying Club **金卡**，也就是**天合聯盟超級精英**。

## 一、可以匹配的航空公司

| 航空公司 | 會員計畫 | 換金卡（最高等級） | 換銀卡（第二等級） |
| --- | --- | --- | --- |
| **阿提哈德（新）** | Etihad Guest | 金卡、白金卡、Emerald | 銀卡 |
| **卡達（新）** | Privilege Club | 白金卡、金卡 | 銀卡 |
| **國泰航空** | 馬可孛羅會 | **鑽石卡** | **金卡** |
| 阿聯酋 | Skywards | 白金卡、金卡 | 銀卡 |
| 英航 | The British Airways Club | 金卡 | 銀卡 |
| 加航 | Aeroplan | 50K、75K、Super Elite | 25K、35K |
| 印度航空 | Flying Returns | 金卡、白金卡 | 銀卡 |
| 美國航空 | AAdvantage | Executive Platinum、Concierge Key | Platinum Pro |
| 伊比利亞 | Iberia Plus | Platino | Oro |
| 漢莎 | Miles & More | Hon Circle | Senator |
| 南非航空 | Voyager | 白金卡、金卡 | 銀卡 |
| 聯合航空 | MileagePlus | 1K、Global Services | Premier Platinum |

長榮、星宇、華航不在名單上。

## 二、怎麼申請？

| 步驟 | 內容 |
| --- | --- |
| 1 | 加入 Flying Club（免費） |
| 2 | 訂一張**未來的維珍航空機票**，付費或點數都可以；行程裡至少一段要有 **VS 航班號**（維珍代碼共享航班也算） |
| 3 | 填匹配表單，附上原航空公司的會員卡照片（要有姓名、等級、到期日） |

| 想換 | 機票艙等 |
| --- | --- |
| **金卡** | **豪華經濟艙（Premium）或 Upper Class** |
| 銀卡 | 任何艙等 |

有頂級會籍但只訂經濟艙，會給**銀卡**；之後升等到豪經或 Upper Class，可以聯絡維珍申請改成金卡。

## 三、規則

| 項目 | 內容 |
| --- | --- |
| 生效 | 第一段合格航班起飛前 **72 小時**升級 |
| 效期 | 升級起 **12 個月** |
| 續卡 | 金卡要在效期內賺 **1,000** tier points，銀卡 **400** |
| 次數 | **5 年內**只能透過匹配拿一次金卡或銀卡 |
| 改退票 | 沒有提前 72 小時通知就取消或改票，匹配可能被取消 |
| 限制 | 條款寫明同時持有天合聯盟夥伴航空任何等級會員資格的人不適用，申請前先確認 |

## 四、Flying Club 金卡有什麼？

| 權益 | 內容 |
| --- | --- |
| 聯盟等級 | **天合聯盟超級精英（SkyTeam Elite Plus）** |
| 貴賓室 | 維珍 Clubhouse 可帶 1 位同行者；天合聯盟貴賓室 |
| 報到 | 商務艙櫃台 |
| 行李 | 額外行李額度 |
| 優先 | 優先登機、優先通關等地面服務 |

天合聯盟超級精英搭**華航、大韓、法航、荷航、達美**等也能用貴賓室和優先服務。

## 五、台灣讀者怎麼用？

| 情況 | 建議 |
| --- | --- |
| 有國泰鑽石卡、明年要飛倫敦或美國 | 訂一張維珍豪經或 Upper Class，換金卡 |
| 有國泰金卡 | 訂任何艙等，換銀卡 |
| 沒有要搭維珍 | 需要先買維珍機票，不適合 |

維珍的航網以北美、加勒比海為主，其他地區很少，比較適合有跨大西洋行程的人。

## 六、總結

**維珍 Flying Club 會籍匹配新增阿提哈德、卡達，名單共 12 家。** 國泰馬可孛羅鑽石卡可以換 Flying Club 金卡（天合聯盟超級精英），要先訂一張有 VS 航班號的豪經或 Upper Class 機票；效期 12 個月，5 年內只能匹配一次。Chase 轉維珍正在加贈 40%，可以參考[Chase 轉維珍加贈 40%](/chase-virgin-atlantic-transfer-bonus-40-percent-2026)。
