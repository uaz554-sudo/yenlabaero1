# 美國航空哩程兌換特賣 72 小時！美國境內 8,000 哩起、洛杉磯飛東京羽田 25,000 哩，2027 年 1～2 月搭乘、台灣時間 11/12 下午 2 點前訂

**新聞分類：哩程資訊／寰宇一家**
**發布日期：2026 年 11 月 10 日**

**美國航空 AAdvantage** 推出 **72 小時**的經濟艙哩程兌換特賣，全網路超過 **100 萬個**主艙（Main Cabin）座位降價：美國境內單程 **8,000 哩**起，飛**歐洲 22,500 哩**起，飛**亞洲與南太平洋 25,000 哩**起。搭乘期間 **2027 年 1 月 11 日～2 月 28 日**，要在**台灣時間 11 月 12 日下午 1:59** 前訂位。

## 一、活動重點

| 項目 | 內容 |
| --- | --- |
| 活動 | AAdvantage 冬季哩程兌換特賣（Award Flash Sale） |
| 訂位期間 | **2026/11/9～11/11 晚上 11:59（美國中部時間）** |
| 台灣時間截止 | **2026/11/12（四）下午 1:59** |
| 搭乘期間 | **2027/1/11～2/28**（航段要在 2/28 前飛完） |
| 艙等 | **經濟艙（Main Cabin）**，豪經、商務、頭等不適用 |
| 黑名單日期 | **沒有**，週末、連假也有特價位 |
| 適用航班 | 美國航空與 American Eagle **自行行銷、自行營運**的航班 |

## 二、各區域單程起價

| 航線（以美國本土 48 州為起點） | 特賣起價（單程） |
| --- | --- |
| 美國本土 48 州境內（不含阿拉斯加、夏威夷） | **8,000 哩** |
| 芝加哥 ⇄ 美國本土 48 州 | **7,000 哩** |
| 美國 ⇄ 墨西哥、加勒比海、中美洲 | **8,000 哩** |
| 美國 ⇄ 南美洲 | **12,000 哩** |
| 美國 ⇄ 歐洲、中東、印度 | **22,500 哩** |
| 美國 ⇄ 亞洲、南太平洋 | **25,000 哩** |

_起價是活動開始時的價格，實際哩程依航班與日期浮動；部分歐洲航班曾出現 21,000 哩的價格。_

## 三、實際查到的特價範例

| 航線 | 哩程（單程） | 備註 |
| --- | --- | --- |
| 紐約拉瓜迪亞 → 波士頓 | **7,000 哩** + 5.6 美元（約 NT$183） | 比廣告的 8,000 哩更低 |
| 費城 → 洛杉磯（橫跨美國） | **8,000 哩** | 長程國內線一樣適用 |
| 華盛頓雷根 → 土克凱可群島 | **8,000 哩** | 加勒比海海島 |
| 紐約甘迺迪 → 倫敦希斯洛 | **21,000 哩** + 5.6 美元 | 同航班現金票約 358 美元（約 NT$11,681） |
| 北卡羅來納 → 瑞士蘇黎世 | **22,500 哩** | 1 月馬丁路德紀念日連假 |
| **洛杉磯 → 東京羽田** | **25,000 哩** | 亞洲線特價 |
| 洛杉磯 → 雪梨 | **25,000 哩** | 南太平洋特價 |

## 四、對台灣讀者的意義

- **飛日本：** 這次亞洲線特價出現**洛杉磯－東京羽田 25,000 哩**，適合 1～2 月要從美國西岸回亞洲、或在美國唸書工作的人。
- **只限美航自營：** 日航、國泰等寰宇一家夥伴的航班**不適用**，台北出發的航班也不在特賣範圍內。
- **在美國境內轉機：** 美國本土 8,000 哩起，搭配從台灣飛美國的長程機票，可以拿來接駁到美國其他城市。

## 五、注意事項

- **不能套用到已訂機票：** 活動不能追溯。如果手上已有 1～2 月的美航哩程票，可以查同航班的特價，**取消原票退回哩程後再重訂**（取消前先確認特價位還在）。
- **座位有限：** 特價位數量有限，哩程依供給變動。
- **稅金另付：** 美國國內線稅金約 5.6 美元起，國際線稅金另計。
- 不能和其他優惠併用；美國航空可隨時調整或提前結束活動。

## 六、總結

**美國航空這次 72 小時特賣，經濟艙美國境內 8,000 哩、歐洲 22,500 哩、亞洲 25,000 哩起，2027/1/11～2/28 搭乘，沒有黑名單日期，台灣時間 11/12 下午 1:59 截止。** 雖然不是史上最低價，但特價位開得很多；1～2 月有美國行程、手上又有 AAdvantage 哩程的人，可以趁這兩天訂。
