# 曼谷 Mövenpick BDMS 健康度假村 2027/1/7 退出雅高，傳將改掛萬豪 EDITION；點數訂房會被取消

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 23 日**

曼谷的 **Mövenpick BDMS Wellness Resort Bangkok** 將在 **2027 年 1 月 7 日**退出雅高。市場傳聞它會在大規模整修後，改掛**萬豪旗下的 EDITION**，但官方還沒證實。

## 一、重點整理

| 項目 | 內容 |
| --- | --- |
| 退出雅高 | **2027/1/7** |
| 過渡名稱 | 1/8 起改名 **Bangkok BDMS Wellness Hotel** |
| 之後 | 交給新的管理公司 |
| 傳聞 | 整修後成為**萬豪 EDITION**（官方未證實） |

## 二、已經訂房的人怎麼辦？

| 情況 | 處理方式 |
| --- | --- |
| **付費訂房** | 照常有效，日期、房型、房價、內含項目不變 |
| **ALL 點數訂房** | **會被取消** |
| 跨 1/7 的住宿 | 1/7 當晚以前照常賺點，之後的晚數不賺點 |
| 1/7 之後的住宿 | **不能賺、不能用** ALL 點數 |
| 會員禮遇 | 免費升等、迎賓飲料、延遲退房等**仍提供** |
| Accor+ 折扣 | 餐飲折扣等 **不提供** |

奇怪的是，這間飯店目前在雅高官網仍可訂到 2027 年底，甚至出現在 Red Hot Rooms 特價。

## 三、對旅客的影響

| 情況 | 建議 |
| --- | --- |
| 1/7 後用點數訂了 | 會被取消，盡早改訂其他飯店 |
| 想用 Accor+ 折扣 | 1/7 後不適用 |
| 想等 EDITION | 要等整修完成，時間未定 |

雅高最近在曼谷陸續流失飯店，這是又一間。

## 四、總結

**曼谷 Mövenpick BDMS 健康度假村 2027/1/7 退出雅高，1/8 起改名過渡，傳聞將整修成萬豪 EDITION（未證實）。** 付費訂房照常有效，點數訂房會被取消，1/7 後不能賺或用 ALL 點數。
