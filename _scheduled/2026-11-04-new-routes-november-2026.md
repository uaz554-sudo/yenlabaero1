# 11 月全球約 50 條新航線開航！土航飛成都天府、紐航基督城直飛成田、阿斯塔納航空首飛日本，7 條重點航線一次看

**新聞分類：航空資訊**
**發布日期：2026 年 11 月 3 日**

11 月全球約有 **50 條新航線**開航，其中幾條很有代表性：**卡達航空**成為第一家飛委內瑞拉的海灣航空公司、**土耳其航空**新開**成都天府**、**紐西蘭航空**從基督城直飛**東京成田**、**阿斯塔納航空**首次飛日本。以下整理 7 條重點航線。

## 一、7 條重點新航線總表

| 首航日 | 航空公司 | 航線 | 班次 | 機型 |
| --- | --- | --- | --- | --- |
| **11/4** | 卡達航空 | 杜哈－波哥大－卡拉卡斯－杜哈 | 每週 2 班 | 777-200LR |
| **11/11** | 土耳其航空 | 伊斯坦堡－**成都天府** | 每週 3 班 | 787-9 |
| **11/20** | IndiGo | 孟買－三蘭港（坦尚尼亞） | 每天 | A320neo |
| **11/26** | 巴拿馬航空 | 巴拿馬市－瑪格麗特島（委內瑞拉） | 每週 3 班 | 737-700／800 |
| **11/28** | 紐西蘭航空 | 基督城－**東京成田** | 每週 3 班 | 787-9 |
| **11/30** | 紐西蘭航空 | 基督城－伯斯 | 每週 3 班 | 787-9 |
| **11/30** | 阿斯塔納航空 | 阿拉木圖－**東京成田** | 每週 2 班 | A321LR |

## 二、亞洲相關航線

### 土耳其航空 伊斯坦堡－成都天府

| 項目 | 內容 |
| --- | --- |
| 首航 | **11 月 11 日** |
| 班次 | 每週 3 班，787-9 |
| 伊斯坦堡出發 | 週三、週五、週日 |
| 成都出發 | 週一、週四、週六 |
| 中國航點 | 北京首都、上海浦東、廣州，加上成都共 **4 個** |
| 競爭 | 四川航空已經飛成都天府－伊斯坦堡 |

土航今年積極把運能轉向亞洲：2026 年夏季伊斯坦堡飛亞洲的單向座位數**年增 17.8%**，飛中國大陸的座位**年增 71.5%**，主因是中東局勢變化改變了客流。

### 紐西蘭航空 基督城－東京成田、基督城－伯斯

| 航線 | 首航 | 班次 | 上次飛 |
| --- | --- | --- | --- |
| 基督城－**東京成田** | **11 月 28 日** | 每週 3 班，787-9 | **2015 年** |
| 基督城－伯斯 | **11 月 30 日** | 每週 3 班，787-9 | **2019 年** |

紐航的 787-9 先前因引擎維修問題停飛一部分，現在陸續復飛、加上新飛機交機，才有運能開這兩條線。**台灣旅客**想去紐西蘭南島，可以考慮從東京成田轉紐航直飛基督城，不必先到奧克蘭。

### 阿斯塔納航空 阿拉木圖－東京成田

| 項目 | 內容 |
| --- | --- |
| 首航 | **11 月 30 日** |
| 班次 | 每週 2 班 |
| 阿拉木圖出發 | 週一、週四 |
| 東京出發 | 週二、週五 |
| 機型 | **A321LR**：商務艙 16 席、經濟艙 150 席 |
| 意義 | 阿斯塔納航空**第一個日本航點**，也是今年第 **22** 條新航線 |
| 合作 | 與**日本航空共掛班號**，可接日本國內線 |

## 三、其他地區

### 卡達航空 杜哈－波哥大－卡拉卡斯

| 項目 | 內容 |
| --- | --- |
| 首航 | **11 月 4 日**，比原定的 7 月**晚了 3 個多月** |
| 延後原因 | 委內瑞拉地震 |
| 航線 | 三角航線：杜哈→波哥大→卡拉卡斯→杜哈 |
| 班次 | 每週 2 班，777-200LR |
| 意義 | **第一家飛委內瑞拉的海灣航空**，也是中東首條直飛波哥大、卡拉卡斯的航班 |
| 轉機 | 經杜哈接澳洲、中國、日本、黎巴嫩、韓國、阿聯酋 |

### 巴拿馬航空 巴拿馬市－瑪格麗特島

| 項目 | 內容 |
| --- | --- |
| 首航 | **11 月 26 日** |
| 班次 | 每週 3 班（週二、週四、週日），737-700／800 |
| 年座位數 | 超過 **45,000** 席 |
| 委內瑞拉航點 | 第 **6** 個（另有巴塞隆納、巴基西梅托、卡拉卡斯、馬拉開波、瓦倫西亞） |
| 轉機 | 經巴拿馬市接 50 多個航點 |

### IndiGo 孟買－三蘭港

| 項目 | 內容 |
| --- | --- |
| 首航 | **11 月 20 日** |
| 班次 | 每天，A320neo |
| 意義 | **唯一**直飛孟買－三蘭港的印度航空公司 |
| 非洲航點 | 奈洛比、模里西斯、塞席爾，加上三蘭港 |
| 機隊 | 結束濕租 787，2028 年起引進自己的 A350 |

## 四、總結

**11 月全球約 50 條新航線開航，亞洲相關的有土航伊斯坦堡－成都天府（11/11）、紐航基督城－東京成田（11/28）、阿斯塔納航空阿拉木圖－東京成田（11/30）。** 對台灣旅客來說，紐航基督城－成田多了一條從東京直飛紐西蘭南島的選擇。
