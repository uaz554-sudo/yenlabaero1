# 國泰「Rewarding Journeys」完成 7 個任務送 6,000 亞洲萬里通＋500 美元機票券！轉點、App 簽到就能拿，到 2027/1/16

**新聞分類：哩程資訊／寰宇一家**
**發布日期：2026 年 11 月 17 日**

**國泰航空**推出「**Rewarding Journeys**」活動：**2026/11/16～2027/1/16** 完成 7 個任務，最多送 **6,000 亞洲萬里通哩數**，完成 2 個以上還送**機票券**，7 個全完成最高 **500 美元**。這次**不需要受邀**，香港和菲律賓以外的會員都能參加，**台灣會員可以**。

## 一、活動重點

| 項目 | 內容 |
| --- | --- |
| 期間 | **2026/11/16～2027/1/16** |
| 登記 | **要先登記**才算 |
| 資格 | 居住在**香港、菲律賓以外**的國泰會員 |
| 最多加贈 | **6,000 哩** |
| 機票券 | 完成 2 個以上任務，**10～500 美元** |
| 入帳期限 | 任務哩程要在 **2027/2/16 前**入帳 |
| 加贈發放 | 2027/3/16 前 |

## 二、7 個任務

| 任務 | 條件 | 加贈 |
| --- | --- | --- |
| ① | 賺或用至少 **1 哩** | 100 |
| ② | 在 **Asia Miles by Cathay App** 簽到並開啟推播 | 50 |
| ③ | 從**支付夥伴**（信用卡等）賺 **8,000 哩** | 800 |
| ④ | 從**度假夥伴**賺 **1,000 哩** | **1,500** |
| ⑤ | **訂一張機票** | 1,200 |
| ⑥ | 從**購物夥伴**賺 **500 哩** | 550 |
| ⑦ | 累計**兌換 15,000 哩** | **1,800** |
| **合計** | | **6,000** |

- 任務②要用「**Asia Miles by Cathay**」App，不是國泰航空 App。
- 任務⑤是否包含獎勵機票，條款沒寫清楚。

## 三、機票券

| 完成任務數 | 機票券 | 約新台幣 |
| --- | --- | --- |
| 2 個 | 10 美元 | 326 元 |
| 3 個 | 20 美元 | 653 元 |
| 4 個 | 50 美元 | 1,631 元 |
| 5 個 | 100 美元 | 3,263 元 |
| 6 個 | 300 美元 | 9,788 元 |
| **7 個** | **500 美元** | **16,314 元** |

_以 Mastercard 1 美元 ≈ 32.63 元換算。_

## 四、台灣會員怎麼拿？

| 任務 | 台灣怎麼做 |
| --- | --- |
| ① 賺或用 1 哩 | 做完其他任務就會順便達成 |
| ② App 簽到 | 下載 Asia Miles by Cathay App，最簡單 |
| ③ 轉 8,000 哩 | 台灣有多家信用卡紅利可轉亞洲萬里通，**注意最低轉點單位**，有些銀行一次要轉 1 萬哩 |
| ④ 度假夥伴 | 透過亞洲萬里通的訂房、旅遊夥伴賺 1,000 哩，加贈 1,500 哩，CP 值最高 |
| ⑤ 訂機票 | 本來就要訂國泰機票的人，活動期間訂 |
| ⑥ 購物夥伴 | 國泰購物、Milesback 網購、Airalo eSIM 等 |
| ⑦ 兌換 15,000 哩 | 本來就要換國泰或寰宇一家獎勵票的人，活動期間累計兌換滿 15,000 哩 |

**最容易的組合：** ①②③④⑥ 五個任務＝ **3,000 哩＋100 美元機票券**；再加上本來就要換的獎勵票（⑦），變成 6 個任務＝ **4,800 哩＋300 美元**。

## 五、要注意

- **先登記**，再做任務。
- 有些銀行、購物平台入帳要好幾週，**2/16 前**要入帳，早點做。
- 任何賺哩或用哩都能讓整個帳戶的哩程**延長 18 個月效期**。
- 國泰燃油附加費今年漲不少，兌換機票時留意稅金。

## 六、總結

**國泰 Rewarding Journeys 到 2027/1/16，完成 7 個任務最多送 6,000 亞洲萬里通＋500 美元機票券，台灣會員也能參加。** 先登記，App 簽到、信用卡轉點、度假夥伴這幾項很容易完成。
