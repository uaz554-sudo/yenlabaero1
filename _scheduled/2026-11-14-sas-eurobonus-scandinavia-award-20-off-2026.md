# 北歐航空 SAS EuroBonus 北歐境內獎勵票 8 折！經濟艙、商務艙都打折，搭乘到 2027/3/31，11/15 截止

**新聞分類：哩程資訊／天合聯盟**
**發布日期：2026 年 11 月 14 日**

**北歐航空 SAS EuroBonus** 推出北歐境內獎勵票 **8 折**：**2026 年 11 月 15 日**前訂，搭乘到 **2027 年 3 月 31 日**，丹麥、挪威、瑞典之間的經濟艙、商務艙獎勵票都打折。冬天想去北歐看極光、滑雪的人可以注意。

## 一、活動重點

| 項目 | 內容 |
| --- | --- |
| 訂位期限 | **2026/11/15 午夜（歐洲中部時間）** |
| 搭乘期間 | **2026/11/12～2027/3/31**，去回程都要在期間內完成 |
| 適用範圍 | **丹麥、挪威、瑞典**之間的航班 |
| 艙等 | **經濟艙 Bonus、商務艙 Bonus** |
| 折扣 | **8 折**，單程、來回都適用 |
| 兒童 | 2～11 歲在折扣價上**再半價** |
| 嬰兒 | 若替嬰兒訂座位，半價 |

## 二、注意事項

| 規則 | 內容 |
| --- | --- |
| 計價 | 依起訖點計價，直飛或轉機同價 |
| 票種 | 只限 **SAS Bonus 機票**，點數＋現金與一般點數票不適用 |
| 稅費 | 機場稅與附加費另付，**不能用點數支付** |
| 座位 | 獎勵位**有限** |
| 更改 | 活動訂位期結束後不能更改，否則恢復原價 |
| 併用 | 不能和其他獎勵優惠併用（SAS Mastercard FlyPremium 2～4 級除外） |

## 三、熱門北歐冬季航線

| 航線 | 適合 |
| --- | --- |
| 斯德哥爾摩 → 斯瓦巴（朗伊爾城） | 北極圈、極地體驗 |
| 哥本哈根 → 特羅姆瑟 | 看**極光** |
| 斯德哥爾摩 → 基律納 | 冰旅館、極光 |
| 奧斯陸 → 博德、特羅姆瑟 | 挪威北部 |

## 四、對台灣讀者的意義

- 北歐航空是**天合聯盟**成員，SAS EuroBonus 點數可以累積、兌換。
- 從台灣飛到哥本哈根、斯德哥爾摩或奧斯陸後，北歐境內段用 EuroBonus 點數換，就能省下昂貴的境內機票。
- 活動只到 **11/15**，要訂的人動作要快。

## 五、總結

**SAS EuroBonus 北歐境內獎勵票 8 折，11/15 前訂、搭乘到 2027/3/31，經濟艙、商務艙都適用，兒童再半價。** 冬天要去北歐看極光的人，可以趁這次把境內段用點數訂起來。
