# 美國航空 777 頭等艙停售，美國籍航空國際頭等艙走入歷史；新 777-300ER 有 70 間商務艙套房

**新聞分類：航空資訊／寰宇一家**
**發布日期：2026 年 11 月 23 日**

**美國航空** 11 月 19 日起停售 **777-300ER 的 Flagship First 頭等艙**。聯合、達美早就沒有國際頭等艙，美國航空是最後一家，從此**美國籍航空不再有國際頭等艙**。

## 一、重點整理

| 項目 | 內容 |
| --- | --- |
| 停售 | **2026/11/19** 起的航班 |
| 機型 | 777-300ER，共 **20 架** |
| 取代 | 新的 **Flagship Suite** 商務艙套房 |
| 改裝進度 | 首架 9/2 投入紐約－布宜諾斯艾利斯，**2027 年底**全部改完 |
| 還沒改的飛機 | 原頭等艙座位**以商務艙販售**，商務艙旅客可直接選前兩排 |

## 二、新舊配置比較

| 艙等 | 舊配置 | 新配置 |
| --- | --- | --- |
| 頭等艙 | 8 席 | **取消** |
| 商務艙 | 52 席 | **70 間套房**（含 8 間 Preferred） |
| 豪華經濟艙 | 28 席 | **44 席** |
| Main Cabin Extra | － | 30 席 |
| 經濟艙 | － | 186 席 |
| **總座位** | **304 席** | **330 席** |

新配置的高艙等（含 Main Cabin Extra）共 144 席，約占 44%。

## 三、Flagship Suite 有什麼？

| 項目 | 內容 |
| --- | --- |
| 座椅 | 全平躺 |
| 隱私 | **有門** |
| Preferred 套房 | 8 間，空間和床更大 |
| 娛樂 | 每個座位都有螢幕、藍牙 |
| Wi-Fi | AAdvantage 會員免費 |

這款套房也已經用在 787-9 和 A321XLR。

## 四、地面服務也一起取消

| 項目 | 變化 |
| --- | --- |
| Flagship First Dining | 已改成 **Flagship Dining**，商務艙旅客也能用 |
| A321T 頭等艙 | 紐約－洛杉磯、舊金山的 A321T 頭等艙，**2027/3/28 起**停售，改由 A321XLR 飛 |

## 五、對哩程玩家的影響

| 情況 | 說明 |
| --- | --- |
| 想用哩程換美國航空頭等艙 | **沒得換了**，要改找其他航空 |
| 寰宇一家頭等艙 | 日航、國泰、卡達、英航等仍有頭等艙 |
| 搭還沒改裝的 777-300ER 商務艙 | 有機會選到原頭等艙座位 |

## 六、總結

**美國航空 11/19 起停售 777-300ER 頭等艙，美國籍航空國際頭等艙正式走入歷史。** 20 架 777-300ER 改成 70 間有門的商務艙套房，2027 年底改完；改裝前原頭等艙座位當商務艙賣。A321T 頭等艙 2027/3/28 起也會停售。
