# 雅高 ALL × 越南航空 Lotusmiles 雙向轉點加贈 30%，到 11/30：3,000 點可換 2,600 哩

**新聞分類：哩程資訊／天合聯盟**
**發布日期：2026 年 11 月 19 日**

**雅高 ALL** 和**越南航空 Lotusmiles** 推出**雙向轉點加贈 30%**，**11 月 2 日到 30 日**轉換都適用。越南航空是天合聯盟成員，台灣有直飛河內、胡志明市的航班。

## 一、活動重點

| 項目 | 內容 |
| --- | --- |
| 期間 | **2026/11/2～11/30** |
| 加贈 | **30%** |
| 方向 | **ALL → Lotusmiles、Lotusmiles → ALL 都適用** |

## 二、轉換比例

| 方向 | 平常 | 加贈後 |
| --- | --- | --- |
| ALL → Lotusmiles | 3,000 點 → 2,000 哩 | 3,000 點 → **2,600 哩** |
| Lotusmiles → ALL | 6,000 哩 → 1,000 點 | 6,000 哩 → **1,300 點** |

## 三、划不划算？

| 項目 | 說明 |
| --- | --- |
| ALL 點數價值 | 折抵雅高住宿，**每點約 0.02 歐元** |
| 3,000 點 ALL | 約可折抵 **60 歐元**住宿 |
| 換成 2,600 哩 | 等於每哩成本約 2.3 歐分 |
| Lotusmiles → ALL | 6,000 哩只換 1,300 點（約 26 歐元），**很不划算** |

**ALL 點數直接折抵住宿通常比較好**。只有點數快到期、又剛好差一點哩程就能換越南航空獎勵票的時候，才值得轉。

## 四、Lotusmiles 可以怎麼用？

| 用途 | 說明 |
| --- | --- |
| 越南航空獎勵票 | 台灣飛河內、胡志明市，或經越南轉機 |
| 天合聯盟夥伴 | 可兌換天合聯盟航空獎勵票 |
| 升等 | 越南航空付費機票升等 |

## 五、總結

**雅高 ALL × 越南航空 Lotusmiles 雙向轉點加贈 30% 到 11/30：ALL 3,000 點可換 2,600 哩。** ALL 點數每點約 0.02 歐元，轉成哩程大多不划算，**點數快到期、又剛好需要越南航空哩程**的人再考慮。雅高最近的會員規則變化，可以參考[雅高 ALL 行政酒廊規則釐清](/accor-all-lounge-access-rule-fairmont-gold-2026)。
