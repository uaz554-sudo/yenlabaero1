# 卡達航空杜哈飛芝加哥 QR725 機上打人！旅客攻擊前排乘客，落地後 FBI 和警方登機帶走

**新聞分類：航空資訊／寰宇一家**
**發布日期：2026 年 11 月 17 日**

**卡達航空** 11 月 16 日從**杜哈**飛**芝加哥**的 **QR725**，航程中發生**旅客打人**事件。機長在落地前聯絡航管要求警方待命，飛機抵達後 **FBI 和警方**登機把嫌犯帶走。

## 一、事件經過

| 時間（當地） | 經過 |
| --- | --- |
| 11/16 08:08 | 從杜哈起飛（表定 07:40，晚 28 分鐘） |
| 航程中 | 坐**第 32 排**的旅客疑似**攻擊第 31 排乘客**，多名旅客目擊，組員與旅客介入制止 |
| 落地前 | 機長聯絡芝加哥航管，要求**警方在登機門待命** |
| 13:46 | 降落芝加哥歐海爾機場 28C 跑道（表定 14:30） |
| 落地後 | 滑行到**第 5 航廈**，FBI 與警方登機，**嫌犯被帶走**、目擊者作筆錄 |

- 飛行時間 **14 小時 38 分鐘**。
- 事件沒有被當成危及生命的狀況，所以**沒有轉降**。
- 卡達航空尚未回應。

| 註冊號 | **A7-BAC** |
| 機型 | 波音 777-300ER |
| 首飛 | 2008/7/9 |
| 交機 | 2008/8/30 |
| 機齡 | 約 **18.4 年** |
| 座位 | 商務艙 **42** 席、經濟艙 **312** 席 |

## 三、機上遇到鬧事怎麼辦？

| 情況 | 建議 |
| --- | --- |
| 看到衝突 | 立刻按服務鈴通知組員，不要自己動手 |
| 自己被攻擊 | 盡量遠離、保護自己，請組員協助換座位 |
| 落地後 | 配合警方作證，保留登機證、照片等資料 |
| 鬧事的後果 | 在美國，機上干擾組員或攻擊他人屬**聯邦案件**，可能面臨罰款與起訴 |

## 四、總結

**卡達航空 QR725 杜哈－芝加哥航程中，第 32 排旅客疑似攻擊前排乘客，組員與旅客制止後繼續飛，落地後 FBI 和警方登機帶走嫌犯。** 長途航班遇到衝突，第一時間找組員處理最安全。
