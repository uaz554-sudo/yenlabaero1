# 星宇 × 蔡依林 2027 台北演唱會：買指定航線商務艙送購票序號保證入場，限量 600 組、代碼 ILOVEJOLIN

**新聞分類：航空資訊／無聯盟**
**發布日期：2026 年 11 月 26 日**

**星宇航空**再度成為蔡依林「**PLEASURE 世界巡迴演唱會 TAIPEI 2027**」的指定夥伴。COSMILE 會員買指定航線的**商務艙**，就送一組演唱會**購票序號**，保證入場，限量 **600 組**。

## 一、活動內容

| 項目 | 內容 |
| --- | --- |
| 對象 | **COSMILE 會員** |
| 期間 | 即日起到 **2026/12/16** |
| 代碼 | **ILOVEJOLIN** |
| 購買管道 | 星宇官網或 App |
| 艙等 | **商務艙** |
| 出發日 | **2027/2/15（含）以後** |
| 贈品 | 演唱會購票序號 1 組，可買 **5,990 元或 6,990 元**票區門票 **2 張** |
| 另外 | 機票折扣 1% |
| 名額 | 限量 **600 組**，送完為止 |

## 二、適用航線（台灣出發）

| 地區 | 航點 |
| --- | --- |
| 美國 | 洛杉磯、安大略、舊金山、西雅圖、鳳凰城 |
| 歐洲 | 布拉格 |
| 大洋洲 | 澳洲、紐西蘭 |

蔡依林也是星宇**台北－布拉格**航線大使，重新詮釋了《布拉格廣場》。

## 三、要注意

| 項目 | 說明 |
| --- | --- |
| 序號是購票資格 | 拿到序號後還要自己買演唱會門票 |
| 出發日 | 2/15 以前出發的不適用 |
| 經濟艙、豪經艙 | 不適用 |

## 四、總結

**星宇 COSMILE 會員到 12/16 用代碼 ILOVEJOLIN 買美國、布拉格、澳紐商務艙（2027/2/15 以後出發），送蔡依林台北演唱會購票序號 1 組（2 張），限量 600 組。** 本來就要買星宇長程商務艙、又想看演唱會的人可以參考。
