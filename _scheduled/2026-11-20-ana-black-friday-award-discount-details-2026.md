# ANA 黑五減哩獎勵票公布！國內線最低 3,000 哩、國際線經濟艙 5 折，11/20～11/24 訂，台灣航線不在內

**新聞分類：哩程資訊／星空聯盟**
**發布日期：2026 年 11 月 20 日**

全日空 **ANA** 原本說黑五減哩獎勵票 11/24 公布，結果**提前在 11/20 上線**，訂位期間只有 **11/20～11/24** 五天。國內線全部航線打折，國際線經濟艙 **5 折**，但**台灣航線不在名單內**。

## 一、活動重點

| 項目 | 國內線 | 國際線 |
| --- | --- | --- |
| 訂位、開票 | **2026/11/20 00:00～11/24 23:59**（日本時間） | 11/20 00:00（日本時間）～11/24 23:59（開票國時間） |
| 管道 | **只限 ANA 官網** | **只限 ANA 官網** |
| 航線 | **全部國內線，直飛行程** | 指定航線，**只限經濟艙** |
| 搭乘期間 | **2027/1/7～2/28** | 依航線不同 |

期間內要**訂好並開票**，期間外開票不適用；候補到期間外才有位也不適用。

## 二、國內線：最低 3,000 哩

| 距離 | 平常單程 | 活動單程 | 例子 |
| --- | --- | --- | --- |
| 0～300 哩 | 6,000 哩 | **3,000 哩** | 東京－大阪 |
| 301～800 哩 | 7,000 哩 | **4,000 哩** | 東京－福岡、大阪－札幌 |
| 801～1,000 哩 | 8,000 哩 | **5,000 哩** | 東京－沖繩 |
| 1,001～2,000 哩 | 9,500 哩 | **7,500 哩** | － |

只限直飛行程。

## 三、國際線經濟艙 5 折（單程）

| 地區 | 航線 | 活動單程 |
| --- | --- | --- |
| 中國 | 羽田、成田、關西－上海、北京；羽田－深圳、廣州、青島；成田－大連、杭州 | **4,250**／5,000／7,500 哩 |
| 香港 | 羽田、成田－香港 | **4,250**／5,000／7,500 哩 |
| 東南亞 | 羽田、成田－曼谷、雅加達、吉隆坡；成田－新加坡 | **7,500**／8,750／12,500 哩 |
| 夏威夷 | 成田－檀香山（羽田航班不適用） | **8,750**／10,000 哩 |
| 北美 | 成田－洛杉磯、舊金山、芝加哥；羽田－溫哥華、西雅圖 | **10,000**／12,500 哩 |
| 歐洲 | 羽田－倫敦、巴黎、法蘭克福、慕尼黑、維也納、米蘭、伊斯坦堡、斯德哥爾摩；成田－布魯塞爾 | **11,250 哩** |
| 大洋洲 | 羽田－雪梨、成田－伯斯 | **9,250**／11,250／16,250 哩 |

哩數依淡旺季不同，日期越接近連假越高。

## 四、搭乘期間（部分）

| 地區 | 搭乘期間 | 不適用 |
| --- | --- | --- |
| 中國 | 2026/12/5～2027/6/30 | 12/24～27、1/2～3、1/22～2/21、3/19～4/5 |
| 香港 | 2027/1/11～6/30 | 2/1～14、3/19～4/5、4/28～5/5 |
| 東南亞 | 2027/1/11～6/30 | 3/19～4/5、4/28～5/5 |
| 夏威夷、北美 | 2027/1/13～5/31 | 3/12～31、4/28～5/9 |
| 歐洲 | 2027/1/11～2/28 | － |
| 大洋洲 | 2027/2/1～6/30 | 3/19～4/5、4/28～5/5 |

## 五、限制

| 項目 | 說明 |
| --- | --- |
| 艙等 | 國際線**只限經濟艙** |
| 航班 | **ANA 自營航班**；日本國內線以外的代碼共享不適用 |
| 合作航空 | 行程有其他航空公司就**不適用** |
| 燃油附加費 | 國際線另付，金額不低 |
| 機位 | 數量有限 |

## 六、台灣旅客怎麼用？

| 情況 | 建議 |
| --- | --- |
| 寒假去日本、要搭國內線 | **東京－大阪 3,000 哩**、東京－沖繩 5,000 哩很划算 |
| 想從日本去其他地方 | 日本出發的國際線可以用，台灣出發要另外接 |
| 台灣－日本 | **不在名單內** |

JAL 黑五國際線減哩（台北－沖繩 5,250 哩）可以參考[JAL 黑五國際線減哩](/jal-black-friday-international-award-discount-2026)；ANA 黑五其他活動見[ANA 黑五 11/20 開跑](/ana-black-friday-2026)。

## 七、總結

**ANA 黑五減哩 11/20～11/24 訂，只限官網：國內線全部直飛航線最低 3,000 哩（東京－大阪），國際線經濟艙 5 折。** 台灣航線不在名單內，最適合寒假到日本、要搭日本國內線的人。
