# 柏悅布里斯本 2031 年開幕：河畔 201 間客房，柏悅在澳洲第 4 間、南太平洋第 5 間

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 19 日**

凱悅宣布在澳洲布里斯本開設 **柏悅（Park Hyatt）**，預計 **2031 年**開幕。這是柏悅第一次進入**昆士蘭**。

## 一、飯店基本資料

| 項目 | 內容 |
| --- | --- |
| 名稱 | **Park Hyatt Brisbane** |
| 開幕 | 預計 **2031 年** |
| 位置 | 布里斯本河畔，市中心（CBD）西側 |
| 開發案 | **309 North Quay** 綜合開發案（住宅、零售、飯店） |
| 樓層 | 兩棟大樓中其中一棟的**高樓層**（大樓分別 51、56 層） |
| 客房 | **201 間**客房與套房，看河景與市景 |
| 公寓 | **50 間**服務式公寓，給長住旅客 |

## 二、柏悅在南太平洋

| 城市 | 飯店 |
| --- | --- |
| 雪梨 | 柏悅雪梨 |
| 墨爾本 | 柏悅墨爾本 |
| 坎培拉 | Hyatt Hotel Canberra – A Park Hyatt Hotel |
| 奧克蘭 | 柏悅奧克蘭 |
| **布里斯本** | **柏悅布里斯本（2031 年）** |

開幕後是柏悅在**澳洲第 4 間、南太平洋第 5 間**。

## 三、要注意的地方

| 項目 | 說明 |
| --- | --- |
| 開幕時間 | 開發案**還沒動工**，2031 年可能延後 |
| 外觀 | 目前只有整個開發案的示意圖，飯店本身還沒有設計圖 |
| 凱悅點數 | 柏悅屬凱悅最高端品牌之一，開幕後可用 World of Hyatt 點數兌換 |

## 四、台灣旅客怎麼去？

台灣目前有直飛布里斯本的航班；星宇 2027 年也將開航雪梨、奧克蘭，澳洲、紐西蘭的選擇越來越多。

## 五、總結

**柏悅布里斯本預計 2031 年開幕，位在布里斯本河畔 309 North Quay 大樓高樓層，有 201 間客房與 50 間服務式公寓。** 開幕後是柏悅在澳洲第 4 間、南太平洋第 5 間。開發案還沒動工，開幕時間可能延後。凱悅 2027 年會員制度改變可以參考[凱悅 2027 會員制度大改](/world-of-hyatt-2027-milestone-rewards-changes)。
