# 美國運通點數可以轉 Fanatics 了！第一個非旅遊轉點夥伴，1,000 點換 10 美元 FanCash，每點只值 1 美分

**新聞分類：信用卡／美國信用卡**
**發布日期：2026 年 11 月 10 日**

**美國運通**美國版 **Membership Rewards** 新增 **Fanatics FanCash** 為轉點夥伴，是 Membership Rewards **第一個非旅遊轉點夥伴**。轉換比例是 **1,000 點換 10 美元 FanCash**，等於每點 **1 美分**。

## 一、轉點重點

| 項目 | 內容 |
| --- | --- |
| 新夥伴 | **Fanatics FanCash**（美國運動用品電商 Fanatics 的回饋貨幣） |
| 定位 | Membership Rewards **第一個非旅遊**轉點夥伴 |
| 位置 | 轉點夥伴頁面新增的「**Lifestyle**」分類 |
| 比例 | **1,000 點 → 10 美元 FanCash**（約 NT$326） |
| 每點價值 | **1 美分**（約 NT$0.33） |
| 適用 | 符合資格的**美國**卡友 |
| 綁定 | 輸入 Fanatics 帳號登入資料即可連結 |
| 退回 | **轉出後不能退回** |

## 二、FanCash 可以用在哪？

| 用途 | 說明 |
| --- | --- |
| Fanatics 網站購物 | 1 FanCash = 1 美元，買球衣、帽子、運動服飾 |
| 球員卡、收藏品 | Fanatics 旗下集換式卡牌與收藏品 |
| 球票 | 部分賽事門票 |
| 合作網站 | 部分聯盟官方商店（例如 MLB Shop） |
| 運動博彩 | Fanatics Sportsbook 的回饋貨幣也是 FanCash（限開放的州） |

## 三、划不划算？

| 用法 | 每點價值 |
| --- | --- |
| 轉 Fanatics FanCash | **1 美分** |
| 換現金存入帳戶（限部分卡） | 1 美分 |
| 嘉信 Schwab 白金卡換現金 | 1.1 美分 |
| 轉航空、飯店夥伴（美國常見估值） | 約 **2～2.2 美分** |

- 1,000 點換 10 美元 FanCash，和直接換現金價值差不多，但 FanCash **只能在 Fanatics 體系內使用**。
- 會用航空、飯店轉點的人，價值通常是轉 Fanatics 的 **2 倍以上**。
- 比較可能變划算的情況是未來出現**轉點加贈**，而且剛好有要買的商品。

## 四、Fanatics American Express 卡也要來了

| 項目 | 內容 |
| --- | --- |
| 卡名 | Fanatics American Express® Card |
| 年費 | **免年費** |
| 回饋 | Fanatics 體系消費 **5% FanCash**，透過 Fanatics App 購物 **8% 以上** |
| 卡面 | 超過 **500 款**球員卡風格卡面 |
| 其他 | Fanatics ONE 會員等級提升、運動相關福利 |
| 狀態 | **尚未開放申請**，可先候補登記 |

_這張卡跑美國運通網路，2026 年 5 月和這次轉點合作一起宣布。_

## 五、對台灣卡友的影響

台灣美國運通卡的點數**不能**轉 Fanatics，這次只限美國版 Membership Rewards。不過這代表美國運通開始把轉點夥伴擴大到旅遊以外的領域，之後各國的點數計畫會不會跟進，值得觀察。

## 六、總結

**美國運通 Membership Rewards 新增第一個非旅遊夥伴 Fanatics FanCash，1,000 點換 10 美元，每點 1 美分，轉出不能退。** 對運動迷是多一個用點方式，但會玩航空、飯店轉點的人，價值差了一倍以上；除非出現轉點加贈，不然不太需要轉。
