# 阿拉斯加 Atmos 買點又來了！加贈 90%～100% 起、到 12/19，每點約 1.88～1.98 美分，年度上限加到 25 萬點

**新聞分類：哩程資訊／寰宇一家**
**發布日期：2026 年 11 月 16 日**

**阿拉斯加航空 Atmos Rewards** 又推出買點促銷，到 **12 月 19 日**。上一波 11/7 才結束（見 [阿拉斯加 Atmos 買點加贈 90% 起](/alaska-atmos-buy-points-bonus-november-2026)），這次加贈依帳戶不同，大約 **90%～100%**，部分會員可能更高。

## 一、活動重點

| 項目 | 內容 |
| --- | --- |
| 期間 | **美西時間 2026/11/13 06:00～12/19 23:59** |
| 加贈 | 依帳戶不同，常見 **90%** 或 **100%**，以登入後顯示為準 |
| 原價 | 每 1,000 點 **35 美元**，另加 7.5% 美國聯邦消費稅 |
| 單筆上限 | 加贈前 **10 萬點** |
| 年度上限 | 非菁英會員平常 15 萬點，**活動期間加到 25 萬點**（加贈前）；菁英會員無上限 |
| 資格 | 入會滿 **10 天** |
| 入帳 | 通常即時入帳，**不能退款** |
| 會籍 | 買的點數**不算**會籍點數 |

## 二、90% 加贈的級距（以 OMAAT 帳戶為例）

| 購買點數（加贈前） | 加贈 |
| --- | --- |
| 1,000～2,000 點 | 0% |
| 3,000～9,000 點 | 70% |
| 10,000～19,000 點 | 80% |
| **20,000～100,000 點** | **90%** |

## 三、每點多少錢？

| 加贈 | 含稅每點 | 約新台幣 |
| --- | --- | --- |
| 沒有加贈 | 3.76 美分 | 1.23 元 |
| **90%** | **1.98 美分** | **0.65 元** |
| **100%** | **1.88 美分** | **0.61 元** |
| 110% | 1.79 美分 | 0.58 元 |

**舉例：** 90% 加贈時買 10 萬點，實拿 **19 萬點**，含稅 **3,762.5 美元**（約新台幣 122,762 元）。

_以 Mastercard 1 美元 ≈ 32.63 元換算，另有海外交易手續費。_

## 五、Atmos 點數可以換什麼？

| 類型 | 夥伴航空 |
| --- | --- |
| 寰宇一家 | 美國航空、英航、**國泰**、**日航**、芬蘭航空、伊比利亞、卡達、澳航、馬來西亞航空等 |
| 非聯盟夥伴 | **星宇**、**大韓**、**菲律賓航空**、Condor、冰島航空、愛爾蘭航空、海南航空等 |

- 獎勵票**可以停留**（stopover），現在很少計畫還允許。
- 用點數換的機票**算會籍**，每飛 1 哩算 1 點會籍點數。
- 買點經 **points.com** 扣款，用阿拉斯加聯名卡刷**不算機票消費**。

## 六、台灣讀者怎麼用？

- 台灣出發可以換**星宇**、**國泰**（經香港）、**日航**（經東京）的獎勵票。
- 星宇洛杉磯線最近換機型、商務艙變少，訂之前先確認機型，見 [星宇台北－洛杉磯 2027/1/31～2/27 改派 A350-900](/starlux-taipei-los-angeles-a350-900-swap-2027)。
- 建議先查到獎勵位再買點，買了不能退。

**阿拉斯加 Atmos 買點到 12/19，加贈約 90%～100%，含稅每點 1.88～1.98 美分（約 0.61～0.65 元），年度上限暫時加到 25 萬點。** 這價格和過去幾波差不多，有確定要換星宇、國泰、日航的票再買。
