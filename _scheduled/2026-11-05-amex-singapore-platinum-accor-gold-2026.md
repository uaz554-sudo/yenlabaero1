# 新加坡美國運通白金卡送雅高 ALL 金卡會籍！只限正卡，MR 點數 2.5：1 轉雅高點數，每點約值 1.15 美分

**新聞分類：信用卡／集團體系**
**發布日期：2026 年 11 月 5 日**

**新加坡美國運通 The Platinum Card**（原名 AMEX Platinum Charge）新增一項權益：**免費雅高 ALL 金卡（Gold）會籍**。這是美國運通和雅高今年全球合作的一部分，**Membership Rewards 點數轉雅高點數**上個月也已經上線。不過金卡只給**正卡**，附卡沒有。

## 一、白金卡送雅高金卡

| 項目 | 內容 |
| --- | --- |
| 卡片 | 新加坡 The Platinum Card |
| 會籍 | **雅高 ALL 金卡（Gold）** |
| 對象 | **只限正卡**，附卡不適用 |
| 方式 | 直接升級會籍，不是送會籍晚數 |
| Centurion 黑卡 | 送 **ALL 白金卡（Platinum）**：亞太飯店免費早餐、貴賓室 |

### 雅高金卡禮遇

| 禮遇 | 內容 |
| --- | --- |
| 點數加贈 | **+48%** |
| 升等 | 視房況 |
| 提早入住／延遲退房 | 視房況 |
| 迎賓 | 迎賓飲料券 |

金卡屬於中階會籍，升等、延遲退房都排在白金卡、鑽石卡之後。已經靠 ALL Accor+ Explorer 等方式拿到金卡的人，這項權益沒有太大幫助，因為它不會給會籍晚數，也不能幫你往白金卡前進。

## 二、新加坡白金卡的會籍權益

| 會籍 | 正卡 | 附卡 |
| --- | --- | --- |
| Hilton Honors 金卡 | ✓ | ✓ |
| 萬豪 Bonvoy 金卡 | ✓ | ✓ |
| 泛太平洋 DISCOVERY 白金卡 | ✓ | ✓ |
| Radisson Rewards Premium | ✓ | ✓ |
| Hertz Gold Plus Five Star | ✓ | ✓ |
| **雅高 ALL 金卡** | **✓** | **✗** |

雅高金卡是唯一**只給正卡**的會籍。

## 三、MR 點數轉雅高點數

| 項目 | 內容 |
| --- | --- |
| 比例 | **2.5 MR 點：1 雅高點** |
| 單位 | 每次 1,000 MR 點 |
| 入帳 | 通常即時，最多 48 小時 |
| 手續費 | 無 |
| 年度上限 | 無 |

### 值多少

| 用法 | 雅高點價值 | 每 MR 點約值 |
| --- | --- | --- |
| 住宿時折抵房費、餐飲、SPA | 1,000 點＝**20 歐元** | **約 1.15 美分** |
| 非住宿時折抵餐飲、SPA | 1,000 點＝10 歐元 | 約 0.58 美分 |

用 The Platinum Card 的 MR 點轉航空哩程是 2：1，換算下來等於把哩程用**每哩約 2.3 美分**「兌現」成雅高點數，是目前 MR 點數很划算的用法之一。

## 四、台灣讀者

這是**新加坡發行**的美國運通卡權益，台灣的美國運通卡不適用。台灣白金卡的健身禮遇今年底屆滿，可參考[美國運通白金專屬健身禮遇 12/31 屆滿](/amex-platinum-taiwan-gym-benefit-ends-2027)。雅高其他促銷可看[雅高 ALL 11 月促銷整理](/accor-promotions-november-2026)。

## 五、總結

**新加坡美國運通 The Platinum Card 正卡送雅高 ALL 金卡，享點數 +48%、視房況升等等禮遇；MR 點數 2.5：1 轉雅高點數，每 MR 點約值 1.15 美分。** 金卡禮遇不算強，但轉點價值不錯，有新加坡白金卡的人可以多利用。
