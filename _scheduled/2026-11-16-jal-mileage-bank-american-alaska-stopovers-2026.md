# 用日航哩程訂美國國內線，1.2 萬哩起還能停 3 個城市！美國航空＋阿拉斯加混搭最多停 7 次

**新聞分類：哩程資訊／寰宇一家**
**發布日期：2026 年 11 月 16 日**

想在美國玩好幾個城市？用**日航 JAL Mileage Bank（JMB）**的哩程訂**美國航空**或**阿拉斯加航空**，最低 **12,000 哩**就能**停 3 個城市**。日航自己的範例是：紐約出發，經波士頓、華盛頓、費城再回紐約，經濟艙只要 12,000 哩。

## 一、只搭一家：夥伴獎勵表（單一航空）

只搭**美國航空**或只搭**阿拉斯加航空**時，依**全部航段加總的飛行距離**計價：

| 總飛行距離 | 經濟艙 | 商務艙／頭等艙 |
| --- | --- | --- |
| **1,000 哩以內** | **12,000 哩** | **24,000 哩** |
| 1,001～2,000 哩 | 15,000 哩 | 30,000 哩 |
| 2,001～4,000 哩 | 23,000 哩 | 42,000 哩 |
| 4,001～6,000 哩 | 37,000 哩 | 60,000 哩 |

| 規則 | 內容 |
| --- | --- |
| 航段 | 最多 **6 段** |
| 停留 | 最多 **3 次**（在一個城市待超過 24 小時） |
| 陸路段 | 可以有 1 段（例如飛到 A 城、從 B 城出發），但會**用掉 1 次停留** |
| 艙等 | 美國航空雙艙機型的頭等艙、阿拉斯加頭等艙，以**商務艙價**計算 |
| 限制 | 1,000 哩內很容易超過，城市要挑近的 |

**舉例：** 洛杉磯－芝加哥（停）－邁阿密（停）－聖胡安，總距離超過 1,000 哩，就要用更高的級距。

## 二、混搭：寰宇一家獎勵表

**美國航空和阿拉斯加混搭**時，不能用上面的單一航空表，要改用日航的**寰宇一家獎勵表**：

| 總飛行距離 4,000 哩以內 | 哩程 |
| --- | --- |
| 經濟艙 | **25,000 哩** |
| 商務艙（含美航雙艙頭等、阿拉斯加頭等） | **48,000 哩** |

| 規則 | 內容 |
| --- | --- |
| 航段 | 最多 **8 段**（轉機也算） |
| 停留 | 最多 **7 次**，同一城市只能停 1 次 |
| 範圍 | 可以**全程都在美國境內**，不用加國際線 |

## 三、單一航空 vs. 混搭怎麼選？

| 總距離 2,001～4,000 哩 | 只搭一家 | 混搭兩家 |
| --- | --- | --- |
| 經濟艙 | 23,000 哩 | 25,000 哩 |
| 頭等 | 42,000 哩 | 48,000 哩 |
| 停留次數 | 3 次 | **7 次** |
| 航網 | 只有一家 | 美航＋阿拉斯加 |

多付 **2,000 哩**（經濟艙），就能用兩家航網、多停 4 個城市。兩種獎勵票都可以開**單程**。

## 四、訂位注意事項

| 項目 | 內容 |
| --- | --- |
| 先查位 | 每一段都要有日航能訂到的夥伴獎勵位；英航查得到的位通常日航也訂得到，可能要打電話 |
| 入會時間 | 日航一般規定入會後一段時間（最長 60 天）不能換票，新的轉點合作已放寬 |
| 使用對象 | 只能本人和**符合資格的家人** |
| 更改 | 可以改**日期、航班**，不能改路線或換航空公司 |
| 退票 | 開始旅行後，沒飛的航段**不退哩程** |

## 五、台灣會員要注意

- JMB 台灣會員也能用這個獎勵表，哩程可從**搭日航、寰宇一家航班**累積。
- 美國的 Bilt、Citi、Rove、Capital One 可以轉點到日航，台灣信用卡**不一定**能轉，要看各銀行的合作清單。
- 日航國際線獎勵票限時折扣可以看 [日航 JAL 獎勵機票限時 7 折](/jal-mileage-bank-award-discount-2026)。
- 想用阿拉斯加點數訂，也可以停留，見 [阿拉斯加 Atmos 買點又來了](/alaska-atmos-buy-points-bonus-december-2026)。

## 六、總結

**用日航哩程訂美國國內線，只搭美航或阿拉斯加一家時 1,000 哩內經濟艙 12,000 哩、可停 3 個城市；兩家混搭 4,000 哩內 25,000 哩、可停 7 個城市。** 先查好每一段的獎勵位、確認總距離，再換票。
