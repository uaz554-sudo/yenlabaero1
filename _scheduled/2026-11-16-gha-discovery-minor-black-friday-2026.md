# GHA DISCOVERY 黑五兩波：Minor 歐美飯店最高 55 折＋D$40 只能 11/18 前訂；澳洲 Avani、Oaks 住 2 晚送 D$50

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 16 日**

**Minor 集團**透過 **GHA DISCOVERY** 推出兩波黑色星期五促銷：**歐美**指定飯店最高 **55 折**再送 **D$40**，但**只能訂到 11/18**；**澳洲** Avani、Oaks 住 2 晚以上送 **D$50**，訂到 12/3。

## 一、兩波促銷比較

| 項目 | ① 歐美黑五前哨 | ② 澳洲 Avani、Oaks |
| --- | --- | --- |
| 優惠 | 最高 **55 折**＋**D$40** | 連住 2 晚以上送 **D$50** |
| 訂房期間 | **11/16～11/18** | 11/16～**12/3** |
| 入住期間 | 2026/11/23～**2027/8/15** | 2026/11/16～**2027/3/31** |
| 最少住幾晚 | 未特別規定 | **2 晚**（3 間 Oaks 要 3 晚） |
| D$ 發放 | **入住後**就發，不用等住完入帳 | 住宿完成後 |
| D$ 效期 | **30 天** | **6 個月** |
| 約新台幣 | D$40 ≈ 1,305 元 | D$50 ≈ 1,631 元 |

_D$（DISCOVERY Dollars）1 元約等於 1 美元；新台幣以 Mastercard 1 美元 ≈ 32.63 元換算。_

## 二、① 歐美指定飯店（舉例）

| 國家 | 參加飯店舉例 |
| --- | --- |
| 奧地利 | **Anantara Palais Hansen Vienna**、NH Collection Wien Zentrum、NH Collection Salzburg City |
| 法國 | **Anantara Plaza Nice**、NH Collection Paris Ponthieu Champs-Élysées、nhow Marseille |
| 義大利 | **Anantara Convento di Amalfi**、Avani Rio Novo Venice、NH Collection Venezia Palazzo Dei Dogi、NH Collection Roma Palazzo Cinquecento |
| 克羅埃西亞 | Anantara Adriatic Istria Resort |
| 德國 | nhow Berlin、nhow Frankfurt、NH Collection Berlin Mitte、多間 NH 機場飯店 |
| 比利時、丹麥、芬蘭、匈牙利、捷克 | NH Collection 布魯塞爾、哥本哈根、赫爾辛基、布達佩斯、布拉格 |
| 南美 | 阿根廷、智利、哥倫比亞、厄瓜多的 NH、NH Collection、Avani |

- 參加飯店很多，以 NH 系列為主，訂房時選標示促銷的價格。
- **D$40 入住後就發，但 30 天內要用完**，適合一段時間內會再住 GHA 飯店的人。

## 三、② 澳洲 Avani、Oaks

| 項目 | 內容 |
| --- | --- |
| 適用價格 | DISCOVERY – Black Friday、Black Friday（含或不含早餐） |
| 品牌 | Avani、Oaks、iStay，以及 The Milton Brisbane、WRAP on Southbank |
| 城市 | 布里斯本、墨爾本、阿德雷德、黃金海岸、凱恩斯、達爾文、雪梨北萊德等 |
| 要住 3 晚的飯店 | Oaks Lake Crackenback Resort、Oaks R Suites Geelong、Oaks Vue Suites Geelong |
| 紐西蘭 | GHA 頁面寫澳洲和紐西蘭，但條款只列澳洲飯店 |

## 四、怎麼用最划算？

- **11/18 前**決定明年上半年去歐洲的住宿，可以先訂 55 折的價格；記得看清楚是否可退。
- 澳洲 Oaks 多是**公寓式套房**，適合家庭、長住，住 2 晚就送 D$50。
- GHA DISCOVERY 的 D$ 可以在 GHA 旗下飯店折抵房價、餐飲。
- 11/14 公布的歐美促銷和 11/15 的澳洲促銷是分開的活動，條件不同。

## 五、總結

**Minor 歐美飯店最高 55 折＋D$40 只能 11/16～18 訂、住到 2027/8/15；澳洲 Avani、Oaks 連住 2 晚送 D$50，訂到 12/3、住到 2027/3/31。** 歐美這波時間很短，明年要去歐洲的人這兩天先比價。
