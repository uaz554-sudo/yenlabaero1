# 美國運通萬豪 Bevy 卡史上最高開卡禮！15 萬點＋250 美元回饋，6 個月刷 5,000 美元，2027/1/13 截止

**新聞分類：信用卡／美國信用卡**
**發布日期：2026 年 11 月 14 日**

**美國運通萬豪 Bonvoy Bevy 卡**推出**史上最高開卡禮**：開卡 6 個月內刷滿 **5,000 美元**，送 **15 萬點萬豪點數＋250 美元帳單回饋**，250 美元剛好抵掉第一年年費。活動到 **2027 年 1 月 13 日**。

## 一、開卡禮

| 項目 | 內容 |
| --- | --- |
| 點數 | **150,000 點** Marriott Bonvoy |
| 帳單回饋 | **250 美元**（約 NT$8,157） |
| 門檻 | 開卡 **6 個月內刷 5,000 美元**（約 NT$163,140） |
| 截止 | **2027/1/13** |
| 推薦連結 | 目前不適用這個開卡禮 |

_以 Mastercard 匯率 1 美元 = 32.6279 元換算。_

## 二、卡片權益

| 項目 | 內容 |
| --- | --- |
| 年費 | **250 美元** |
| 萬豪消費 | **6 倍** |
| 餐廳、美國超市 | **4 倍**（每年前 1.5 萬美元） |
| 其他消費 | **2 倍** |
| 會籍 | **萬豪金卡** |
| 等級晚數 | 每年 **15 晚** |
| 住宿加碼 | 每次合格住宿加送 **1,000 點** |
| 免費房券 | 每曆年刷滿 **1.5 萬美元**送 **5 萬點**免費房券 |
| 海外手續費 | **免** |

## 三、划算嗎？

| 項目 | 估算 |
| --- | --- |
| 15 萬點 | 美國部落格估值約 **1,100 美元** |
| 250 美元回饋 | 抵第一年年費 |
| 第二年後 | 沒有週年免費房券，要靠年刷 1.5 萬美元換房券才划算 |

第一年拿開卡禮非常划算；但 Bevy 卡沒有週年房券，長期持有的價值不如萬豪其他卡。

## 四、萬豪卡申請限制

美國萬豪卡分別由美國運通與大通發行，彼此有申請、開卡禮資格限制（例如近期申請過其他萬豪卡可能拿不到開卡禮），申請前請先確認自己的資格。

## 五、對台灣讀者

這是**美國版**信用卡，只限美國申請。台灣讀者可以參考的是：萬豪點數的開卡禮行情，15 萬點已是美國萬豪卡的高水準。

## 六、總結

**美國運通萬豪 Bevy 卡史上最高開卡禮：6 個月刷 5,000 美元送 15 萬點＋250 美元，到 2027/1/13。** 第一年非常划算，但沒有週年房券，第二年要不要留卡再評估。
