# 行政院長卓榮泰提「南北雙空港，臺中大機場」：要擴大台中國際機場規模，配合中部精密智慧產業

**新聞分類：航空資訊／無聯盟**
**發布日期：2026 年 11 月 28 日**

行政院長**卓榮泰** 11 月 25 日在台中樂成宮參拜時，提出「**南北雙空港，臺中大機場**」計畫，要和地方一起**擴大台中國際機場**的規模。

## 一、計畫內容

| 項目 | 內容 |
| --- | --- |
| 名稱 | 南北雙空港，臺中大機場 |
| 南北雙空港 | 北有**桃園國際機場**、南有**高雄國際機場** |
| 台中 | 擴大**台中國際機場**規模 |
| 目的 | 旅客和貨物進出更方便 |
| 配合 | 中彰投雲「中部精密智慧新核心」產業發展 |
| 交通串聯 | 捷運、台 74 線、國道串接等，交通部和台中市政府合作 |

## 二、還不知道的

| 項目 | 狀態 |
| --- | --- |
| 預算 | 沒有公布 |
| 時程 | 沒有公布 |
| 工程內容（跑道、航廈） | 沒有公布 |

行政院說這是「預計逐步推動的願景」，目前是方向，還不是具體工程計畫。

## 三、台中機場最近的國際航線

| 航空公司 | 航線 | 說明 |
| --- | --- | --- |
| 星宇 | 台中－名古屋 | 2026/10/25 開航，11 月起每天飛 |
| 星宇 | 台中－高松 | 每週 5 個來回 |
| 星宇 | 台中－宮古島 | 冬季航班 |
| 星宇 | 台中－峴港 | 明年復飛 |
| 大韓航空 | 台中－仁川 | 恢復天天飛 |

## 四、總結

**卓榮泰提出「南北雙空港，臺中大機場」，要擴大台中國際機場規模，配合中部精密智慧產業發展；但預算、時程和工程內容都還沒公布。** 近期台中機場國際線持續增加，中部旅客出國選擇變多。
