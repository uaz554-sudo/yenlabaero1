# 長榮航太 2027 年維修產能全被訂滿、合約價漲 3～5%：新機延遲交付，航空公司搶維修棚廠

**新聞分類：航空資訊／無聯盟**
**發布日期：2026 年 11 月 26 日**

**長榮航太**（2645）11 月 25 日法說會表示，**2027 年的維修產能已經全部被客戶預訂**，上半年排程已滿，合約價將調漲 **3%～5%**。新飛機交付延遲，航空公司只好讓舊飛機多飛幾年，維修需求跟著變多。

## 一、維修業務

| 項目 | 內容 |
| --- | --- |
| 2027 年產能 | **全數被預訂**，約八到九成已排定進場 |
| 上半年 | 排程已滿 |
| 合約價 | 調漲約 **3%～5%**（反映通膨、人力、物料成本） |
| 2028 年以後 | 訂單也有能見度 |
| 新機型 | 今年第一季取得 **A350** 相關維修認證，首架客戶飛機已完成出廠 |

## 二、為什麼這麼滿？

| 原因 | 說明 |
| --- | --- |
| 新機交付延遲 | 空巴、波音合計積壓約 **1.6 萬架**訂單 |
| 延長機隊使用年限 | 舊飛機要更多維修 |
| 零件短缺 | 供應鏈瓶頸，航空公司更早預留維修時段 |

## 三、擴產計畫

| 項目 | 內容 |
| --- | --- |
| 短期 | 招募第二班人力、提高現有棚廠使用率 |
| 業務組合 | 爭取工期長、技術門檻高的重檢、結構修理 |
| 第五棚廠 | 以取得桃園機場用地為前提，目標 **2031 年**投產 |
| 引擎零件 | 每年增加約 10%～15% 產能 |
| 製造二廠 | 2027 年第三季投產 |

## 四、財務

| 項目 | 第三季 | 前三季 |
| --- | --- | --- |
| 營收 | 52.75 億元（年增 18%） | 152.36 億元（年增 14%） |
| 稅後淨利 | 9.59 億元（年增 31%） | 26.78 億元（年增 72%） |
| EPS | 2.56 元 | **7.15 元** |

## 五、對旅客的影響

飛機維修排程吃緊，代表航空公司更難臨時調度備用飛機；加上新機延遲，舊飛機會飛得更久。長榮航空本身也有 20 架客機全艙等改裝延到明年。

## 六、總結

**長榮航太 2027 年維修產能已全被訂滿、上半年排程已滿，合約價漲 3%～5%；原因是新機交付延遲、航空公司延長舊機使用。** 前三季 EPS 7.15 元，第五棚廠目標 2031 年投產。
