# 希爾頓每次住宿送 2,000 點，不用登錄、沒有上限：11/24～12/1 訂、住到 2027/4/2

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 26 日**

**希爾頓 Hilton Honors** 配合 Cyber Sale 推出加碼：**11 月 24 日到 12 月 1 日**訂房，每次住宿送 **2,000 點**，**不用登錄**、**沒有次數上限**。

## 一、活動內容

| 項目 | 內容 |
| --- | --- |
| 訂房期間 | **2026/11/24～12/1** |
| 入住期間 | 2026/11/25～**2027/4/2** |
| 獎勵 | 每次住宿 **2,000 點** |
| 登錄 | **不用** |
| 上限 | **沒有** |
| 房價 | 依條款看起來**不一定要訂 Cyber Sale 特價房** |
| 適用 | 希爾頓旗下所有飯店 |

部分品牌單次住宿的基本點數有上限，以條款為準。

## 二、美國希爾頓聯名卡加碼

| 項目 | 內容 |
| --- | --- |
| 對象 | 美國希爾頓 Amex 聯名卡持卡人 |
| 訂房 | 2026/11/11～12/22 |
| 入住 | 2026/11/18～2027/4/2 |
| 條件 | 用希爾頓聯名卡**全額付款** |
| 獎勵 | **5,000 點**，限一次 |
| 不適用 | 第三方訂房、團體訂房、點數房 |

## 三、總結

**希爾頓 11/24～12/1 訂房、住到 2027/4/2，每次住宿送 2,000 點，不用登錄、沒有上限。** 年底到明年初有希爾頓住宿計畫的人，這幾天訂房就能多拿點數。
