# 遠雄悅來大飯店加入洲際，2027 年第一季改名「洲至奢選花蓮遠雄悅來酒店」：IHG 首度進東台灣

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 26 日**

花蓮**遠雄悅來大飯店**宣布加入**洲際酒店集團（IHG）**旗下奢華精品品牌「**洲至奢選（Vignette Collection）**」，**2027 年第一季**轉牌為「**洲至奢選花蓮遠雄悅來酒店**」（Farglory Hotel Hualien, Vignette Collection）。

## 一、重點

| 項目 | 內容 |
| --- | --- |
| 新名稱 | **洲至奢選花蓮遠雄悅來酒店** |
| 品牌 | Vignette Collection（洲至奢選） |
| 轉牌時間 | **2027 年第一季** |
| 意義 | IHG **東台灣第一家**、洲至奢選**台灣第一家** |
| 位置 | 海岸山脈北端、海拔約 220 公尺，東望太平洋、西眺中央山脈和花東縱谷 |

## 二、轉牌後的升級

| 項目 | 內容 |
| --- | --- |
| 硬體 | 三年前已完成全館升級 |
| 轉牌後 | 啟動**兩年品牌升級計畫**，重心放在服務與人 |
| 品牌特色 | 洲至奢選保留每家飯店原有名稱、個性和在地故事 |

## 三、洲至奢選是什麼？

| 項目 | 內容 |
| --- | --- |
| 推出 | 2021 年 |
| 目標 | 十年內 100 家，已完成一半以上 |
| 2026 年大中華區新飯店 | 成都、重慶、上海、千島湖、北戴河、三亞、香港 |
| 會員計畫 | IHG One Rewards |

## 四、對 IHG 會員的意義

轉牌後，入住遠雄悅來可以累積和使用 **IHG One Rewards** 點數，會籍禮遇依 IHG 規定。點數房價格要等轉牌後在 IHG 官網公布。IHG 現在買點數加贈 100% 到 12/11。

## 五、總結

**花蓮遠雄悅來 2027 年第一季加入 IHG，改名「洲至奢選花蓮遠雄悅來酒店」，是 IHG 東台灣第一家、洲至奢選台灣第一家。** 轉牌後 IHG 會員可以累積和兌換點數，點數價格等官方公布。
