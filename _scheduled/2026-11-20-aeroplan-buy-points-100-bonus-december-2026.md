# 加航 Aeroplan 買點最高加贈 100%，到 12/10：每點約 0.43 元，換長榮商務艙飛東京 3 萬點

**新聞分類：哩程資訊／星空聯盟**
**發布日期：2026 年 11 月 20 日**

**加拿大航空 Aeroplan** 推出黑五買點活動，**11 月 19 日到 12 月 10 日**，最高加贈 **100%**，部分帳戶還有更高的**神秘加贈**。Aeroplan 可以兌換長榮、全日空等星空聯盟航空，台灣旅客很常用。

## 一、活動重點

| 項目 | 內容 |
| --- | --- |
| 期間 | **2026/11/19～12/10 23:59**（太平洋時間） |
| 最高加贈 | **100%**，部分帳戶更高 |
| 購買管道 | Aeroplan 官網，經 **Points.com** 處理 |
| 單筆上限 | 活動期間從 25 萬點提高到 **50 萬點** |
| 年度上限 | 每年最多買 **100 萬點**（不含加贈） |
| 送人 | 可以直接買給其他 Aeroplan 會員 |
| 退款 | **不能退** |

## 二、加贈級距

| 購買點數 | 加贈 |
| --- | --- |
| 5,000～25,000 點 | **50%** |
| 30,000～80,000 點 | **75%** |
| 90,000 點以上 | **100%** |
| 少於 5,000 點 | 沒有加贈 |

這是條款公開的級距，**實際比例因帳戶而異**，登入後看到的可能更高。活動開始前就已登入的人，要重新整理頁面才會顯示活動價。

## 三、每點成本

| 加贈 | 每點（美分） | 約合新台幣 |
| --- | --- | --- |
| **100%** | **1.31** | **約 0.43 元** |
| 75%（推算） | 約 1.50 | 約 0.49 元 |
| 50%（推算） | 約 1.75 | 約 0.57 元 |

100% 加贈的價格依 LoyaltyLobby 試算；75%、50% 是由 100% 價格推算。台幣依 2026/11/17 Mastercard 匯率 32.6279 換算，發卡行另收國外交易手續費。

**比較：** Aeroplan 過去最低價是 2024 年 125% 加贈時的每點 1.14 美分；2025 年 1 月 100% 加贈時是 1.22 美分。這次 1.31 美分不算最便宜。

## 四、台灣旅客怎麼用？

| 兌換 | Aeroplan 單程 | 比較 |
| --- | --- | --- |
| 長榮商務艙 台北－東京成田 | **30,000 點** | LifeMiles 19,130 哩、無限萬哩遊 25,000 哩 |

以 100% 加贈計算，30,000 點約 **NT$12,800**。同一段 LifeMiles 只要 19,130 哩，買 LifeMiles 比較划算；但 Aeroplan 的優點是：

| 優點 | 說明 |
| --- | --- |
| 夥伴多 | 除了星空聯盟，還有阿聯酋、阿提哈德、海灣航空、阿曼航空等 |
| 線上訂 | 合作航空幾乎都能在官網直接訂，不用打電話 |
| 停留 | 付少量費用可以在行程中停留一站 |

## 五、購買前要注意

| 項目 | 說明 |
| --- | --- |
| 先查位 | 確定有獎勵位再買 |
| 不能退 | 買了就不能退 |
| 不算會籍 | 買的點數不算會籍 |
| 匯率 | 以美元或加幣計價，刷卡有國外交易手續費 |

## 六、總結

**Aeroplan 買點最高加贈 100%，到 12/10；90,000 點以上加贈 100%，每點約 1.31 美分、約 0.43 元。** 價格不是史上最低，但 Aeroplan 夥伴多、可以停留，適合要換星空聯盟或中東航空長程商務艙的人。只換長榮飛日本的話，LifeMiles 更便宜，可以參考[LifeMiles 買哩程加贈 145%](/lifemiles-buy-miles-145-bonus-november-2026)。
