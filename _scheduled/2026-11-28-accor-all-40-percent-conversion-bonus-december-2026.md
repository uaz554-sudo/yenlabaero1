# 雅高 ALL 轉點加贈 40%，到 12/1：卡達 Avios、阿聯酋、越南航空哩程都能轉，3,500 Avios 換 1,400 點

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 28 日**

**雅高 ALL** 推出轉點加贈：**2026 年 11 月 26 日到 12 月 1 日**，從 8 個合作計畫轉入 ALL 點數加贈 **40%**。

## 一、可以轉的計畫

| 計畫 | 平常 | **這次** |
| --- | --- | --- |
| **卡達航空** Privilege Club | 3,500 Avios = 1,000 點 | **3,500 Avios = 1,400 點** |
| **阿聯酋** Skywards | 4,000 哩 = 1,000 點 | **4,000 哩 = 1,400 點** |
| **越南航空** Lotusmiles | 6,000 哩 = 1,000 點 | **6,000 哩 = 1,400 點** |
| 海灣航空 Falconflyer | 4,000 哩 = 1,000 點 | 4,000 哩 = 1,400 點 |
| 肯亞航空 Asante | 3,000 點 = 1,000 點 | 3,000 點 = 1,400 點 |
| IndiGo BluChip | 6,000 = 1,000 點 | 6,000 = 1,400 點 |
| 歐羅巴航空 Suma | 2,000 哩 = 500 點 | 2,000 哩 = 700 點 |
| 巴黎機場 Extime Rewards | 400 點 = 400 點 | 400 點 = 560 點 |

**卡達另外：** ALL 和 Privilege Club 帳戶已連結的話，再加 10%。

## 二、值不值得轉？

| 項目 | 說明 |
| --- | --- |
| ALL 點數價值 | 每點約 **0.02 歐元**，可折抵住宿 |
| 卡達 Avios | 3,500 Avios 換 1,400 點，約 28 歐元；Avios 換商務艙通常更划算 |
| 建議 | 只適合**快過期**、或真的沒有其他用途的哩程 |

## 三、台灣讀者要知道

**台灣目前沒有雅高飯店**，ALL 點數要在海外的 Sofitel、Novotel、Pullman、ibis 等使用。

## 四、總結

**雅高 ALL 11/26～12/1 從卡達、阿聯酋、越南航空等 8 個計畫轉入加贈 40%，卡達 3,500 Avios 換 1,400 點（帳戶連結再加 10%）。** ALL 點數每點約 0.02 歐元，一般只建議用在快過期的哩程。
