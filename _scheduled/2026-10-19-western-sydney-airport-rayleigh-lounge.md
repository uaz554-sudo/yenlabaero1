# 西雪梨新機場第一間貴賓室曝光！The Rayleigh Lounge 11 月開幕，新航商務艙、星空聯盟金卡可用

**新聞分類：航空資訊／星空聯盟**
**發布日期：2026 年 10 月 19 日**
**預計開幕：2026 年 11 月**

10 月 25 日啟用的**西雪梨國際機場（WSI）**，公布國際線貴賓室 **The Rayleigh Lounge**。貴賓室由 **dnata** 經營，會在 **11 月 23 日新加坡航空開航前**開幕。

這是西雪梨機場目前唯一公布的貴賓室，不屬於任何一家航空公司，其他國際航空公司開航後也會陸續加入。

## 一、重點整理

- **名稱：** The Rayleigh Lounge，名字來自藍山上空的藍色霧氣，也就是瑞利散射（Rayleigh scattering）造成的現象。
- **經營：** dnata（阿聯酋航空集團旗下）。
- **位置：** 航廈國際區的夾層，可以看到機坪和遠方的藍山。
- **開幕：** 2026 年 11 月，新航 11/23 首航前。
- **座位：** 初期約 80 席，之後擴大到約 130 席。

## 二、貴賓室設施

| 項目 | 內容 |
| --- | --- |
| 區域 | 個人、家庭、團體分區，另有用餐區 |
| 吧檯 | 環形吧檯，提供軟性飲料、啤酒、葡萄酒、烈酒與咖啡師咖啡 |
| 餐點 | 開放式廚房，自助餐隨時段更換，配合 24 小時營運；主打西雪梨在地食材 |
| 淋浴 | 3 間獨立淋浴室 |
| 其他 | 高速 Wi-Fi、座位旁充電 |

- **設計：** 航廈主建築師 COX Architecture 設計，雪梨設計師 Tom Fereday 負責家具，用溫暖的大地色系和天然材質。

## 三、誰可以使用？

| 旅客 | 可否使用 |
| --- | --- |
| 新航商務艙（SQ262 西雪梨飛新加坡） | 可以 |
| 新航 PPS Club 會員 | 可以 |
| KrisFlyer 金卡會員 | 可以 |
| 星空聯盟金卡會員 | 可以（需搭乘星空聯盟航班） |
| 其他國際航空公司旅客 | 開航後陸續加入 |
| Priority Pass | 尚未公布 |
| 付費入場 | 尚未公布 |

- **晚上的紅眼航班最實用：** 新航 SQ262 晚上 11:55 從西雪梨起飛，貴賓室的淋浴和餐點對搭紅眼班機的人很有幫助。
- **國內線貴賓室：** 澳洲航空 2027 年 3 月 28 日起從西雪梨飛國內線，目前還沒有國內線貴賓室的消息。

## 四、對台灣旅客的影響

- **星空聯盟金卡最好用：** 持長榮無限萬哩遊金卡、鑽石卡等星空聯盟金卡，經新加坡轉機飛西雪梨，回程搭新航時可以使用。
- **先確認是哪座機場：** 訂票時看清楚代碼，SYD 是原本的雪梨機場，WSI 是西雪梨機場。
- **西雪梨機場懶人包：** 航線、交通方式可以參考我們之前整理的[雪梨第二機場 10/25 啟用](/western-sydney-airport-opening-2026)。

## 五、總結

**西雪梨國際機場的國際線貴賓室 The Rayleigh Lounge 由 dnata 經營，11 月新航開航前開幕，初期 80 個座位、3 間淋浴室，新航商務艙、KrisFlyer 金卡、PPS Club 與星空聯盟金卡旅客可以使用。** Priority Pass 與付費入場還沒公布，開幕後我們會再更新。
