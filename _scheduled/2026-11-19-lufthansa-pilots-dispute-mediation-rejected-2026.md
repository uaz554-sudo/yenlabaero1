# 漢莎機師工會：調解方案被公司拒絕，11/23 前要漢莎回頭；今年已罷工 2 次、第一次取消 800 班

**新聞分類：航空資訊／星空聯盟**
**發布日期：2026 年 11 月 19 日**

**漢莎航空**和機師工會 **Vereinigung Cockpit（VC）**的爭議又升溫。工會說調解人提出的方案他們願意接受，但**漢莎拒絕**了。工會給漢莎 **11 月 23 日**的期限。

## 一、事件經過

| 時間 | 事件 |
| --- | --- |
| 2025 年 9 月 | 工會宣布退休金、子公司工作保障談判破裂 |
| 2026/2/12 | 機師罷工 **24 小時**，至少取消 **800 班**、影響約 **13 萬**名旅客 |
| 2026/3/12 起 | 機師罷工 **48 小時** |
| 3 月後 | 進入仲裁與調解，共 **3 輪仲裁、18 輪調解** |
| 2026/11 | 工會願意接受調解方案，**漢莎拒絕**並提出自己的方案 |
| **11/23** | 工會要求漢莎撤回自己的方案、回到調解方案 |

## 二、雙方在吵什麼？

| 議題 | 工會立場 |
| --- | --- |
| 退休金 | 接受**確定給付制**（依年資、職級保證給付）已成過去，願意大幅讓步 |
| 換取 | **長期規劃確定性、工作保障** |
| CityLine | 改善子公司 Lufthansa CityLine 機師的前景 |

工會發言人 Arne Karstens 表示，調解方案「對機師也是大幅縮減」，但他們願意在這個基礎上談細節，漢莎拒絕「完全無法理解」。

## 三、漢莎為什麼要省？

| 背景 | 說明 |
| --- | --- |
| 主品牌拖累 | 漢莎主品牌財務表現拖累整個集團 |
| 子公司 | 成立 CityLine、Discover 等子公司分擔航班，薪資條件較差 |
| 燃油 | 航油成本上升 |
| 過去罷工代價 | 2024 年空服員和地勤聯合罷工，損失至少 **3.5 億歐元** |

## 四、會不會再罷工？

工會**還沒宣布**罷工，但如果漢莎不回應，罷工是可能的下一步。

| 情況 | 建議 |
| --- | --- |
| 年底搭漢莎 | 11/23 後留意漢莎和工會公告 |
| 經法蘭克福、慕尼黑轉機 | 預留轉機時間，或準備替代方案 |
| 已買票 | 若罷工取消，依歐盟 EU261 可能有權退費或改票 |

## 五、總結

**漢莎機師工會說調解方案被公司拒絕，要求 11/23 前撤回。** 今年 2 月、3 月已經罷工 2 次，2 月那次取消至少 800 班。目前還沒宣布新的罷工，年底要搭漢莎或經德國轉機的旅客，11/23 之後記得留意最新消息。
