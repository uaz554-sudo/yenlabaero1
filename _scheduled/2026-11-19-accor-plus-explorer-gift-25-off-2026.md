# 雅高 Accor+ Explorer 送禮會籍 75 折到 11/24：香港買約 6,300 元，送 2 晚住宿券、30 晚會籍直上金卡

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 19 日**

雅高的付費會籍 **ALL Accor+ Explorer** 推出**送禮 75 折**，到 **11 月 24 日**（當地時間）截止。可以買給家人朋友，也可以買給還沒入會的另一個帳號。

## 一、活動重點

| 項目 | 內容 |
| --- | --- |
| 優惠 | 送禮購買 **75 折** |
| 期限 | **2026/11/24 23:59（當地時間）** |
| 對象 | 收禮人必須是**新會員**，不能用來**續約** |
| 每次最多 | 一筆最多買 **10 份** |
| 啟用期限 | 收禮人在指定寄送日後 **12 個月內**啟用 |
| 退款 | 買了**不能取消、退款或換現金** |
| 跨國使用 | 可以在其他符合資格的國家啟用 |

## 二、價格（以香港為例）

| 方案 | 港幣 | 約合新台幣 |
| --- | --- | --- |
| 一般入會 | 1,999 | **8,400** |
| 送禮 75 折 | 約 1,499 | **約 6,300** |

台幣依 2026/11/17 Mastercard 匯率換算。各國價格不同；一般入會到 11/30 另送 3,000 點 ALL 點數（約 60 歐元），**送禮價和加送點數二選一**。

**可購買市場：** 澳洲、香港、印尼、印度、日本、馬來西亞、紐西蘭、菲律賓、新加坡、泰國、越南、阿聯酋。名單裡**沒有台灣**。

## 三、Accor+ Explorer 有什麼？

| 權益 | 內容 |
| --- | --- |
| 住宿 | **2 晚**免費住宿（官網：2 nights on us） |
| 會籍晚數 | **30 晚**，直接達到 **ALL 金卡** |
| 餐飲 | 亞太、中東雅高飯店**餐飲 7 折、飲料 85 折** |
| 房價 | 全球飯店 **85 折** |
| Red Hot Rooms | 亞太、中東限時特價房**最高 5 折** |
| 適用品牌 | 30 個飯店品牌 |

光是 2 晚住宿券，在香港、東京、新加坡的雅高飯店就可能回本。

## 四、誰適合？

| 情況 | 建議 |
| --- | --- |
| 家人還不是 Accor+ 會員 | 用送禮價買，比自己入會便宜 25% |
| 自己已經是會員要續約 | **不適用** |
| 想要 3,000 點加送 | 改用一般入會（到 11/30） |
| 主要住台灣 | 台灣的雅高飯店很少，權益多用在香港、日本、東南亞、澳洲 |

## 五、總結

**Accor+ Explorer 送禮 75 折到 11/24，香港約 1,499 港幣（約 NT$6,300）。** 含 2 晚住宿券、30 晚會籍直上金卡、亞太與中東餐飲 7 折。只限新會員、不能續約，買了不能退。一般入會加送 3,000 點的活動到 11/30，可以參考[Accor+ Explorer 加送 3,000 點](/accor-plus-explorer-3000-bonus-2026)。
