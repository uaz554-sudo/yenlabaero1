# IHG 旗下 Ruby 飯店首度進軍亞太！2027 年曼谷沙吞開幕，184 間房、24 小時酒吧、房內有 Marshall 喇叭還能借吉他

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 7 日**

**IHG 洲際酒店集團**簽下第一家**亞太區 Ruby 飯店**，地點在**曼谷沙吞（Sathorn）**，共 **184 間房**，預計 **2027 年**開幕。這也是 Ruby 這個德國品牌第一次走出歐美。

## 一、飯店資訊

| 項目 | 內容 |
| --- | --- |
| 地點 | 曼谷**沙吞**，主要商業區之一 |
| 房數 | **184 間** |
| 開幕 | **2027 年** |
| 開發商 | 泰國 **Asset World Corp（AWC）** |
| 簽約公布 | 2026/10/28 |
| 設計主題 | **1920 年代暹羅**的熱帶風情，結合音樂與在地故事 |

### 特色

| 設施 | 內容 |
| --- | --- |
| 酒吧 | **24 小時**營業，晚上有現場表演 |
| 房間 | **Marshall 喇叭**，可以**借吉他** |
| 其他 | 大尺寸床、雨淋式淋浴、自助入住等科技服務 |
| 在地合作 | 和在地藝術家、社會企業合作 |

## 二、Ruby 是什麼品牌？

| 項目 | 內容 |
| --- | --- |
| 創立 | 2013 年在**慕尼黑**開第一家，創辦人 Michael Struck |
| 定位 | 「**精簡奢華（lean luxury）**」：房間小但床和淋浴很好，酒吧開到很晚 |
| 命名 | 每家飯店用女性名字，例如 Bea、Lucy、Emma、Zoe |
| IHG 收購 | **2025 年 2 月**，**1.105 億歐元**（約 1.16 億美元），成為 IHG 第 20 個品牌 |
| 收購時規模 | 20 家飯店、3,483 間房，分布在德國、英國、奧地利、瑞士、義大利、愛爾蘭、荷蘭 |
| 擴張目標 | 10 年內超過 120 家、20 年內超過 250 家 |
| 會員 | 可使用 **IHG One Rewards** 累積與兌換點數 |

## 三、IHG 在泰國

- Ruby 會是 IHG 第 **6 個**進入曼谷的品牌，前面有智選假日、英迪格、Staybridge Suites、Kimpton、Vignette Collection。
- IHG 在泰國已有 **42 家**開業飯店，另有 **41 家**籌備中，橫跨 11 個目的地、11 個品牌。
- IHG 表示，曼谷開幕後還會把 Ruby 帶到其他亞太城市。

## 四、對台灣旅客的影響

- **曼谷多一個 IHG 選擇：** 沙吞交通方便，適合商務或喜歡設計感飯店的旅客。
- **用點數住：** 可以用 IHG 點數兌換，也能累積點數與會籍。
- 開幕時間、房價與點數價格公布後，再幫大家整理。

## 五、總結

**IHG 旗下德國品牌 Ruby 2027 年在曼谷沙吞開出亞太第一家，184 間房、1920 年代暹羅主題、24 小時酒吧，房內還有 Marshall 喇叭與吉他可借。** 喜歡小而精緻、重設計的飯店，又有 IHG 會籍的人可以期待。
