# Avios.com 可以搜轉機行程了！英航倫敦、伊比利亞馬德里、愛爾蘭航空都柏林轉機一次比價

**新聞分類：哩程資訊／寰宇一家**
**發布日期：2026 年 11 月 14 日**

**Avios.com** 新增**轉機行程搜尋**：可以一次找英航經**倫敦**、伊比利亞經**馬德里**、愛爾蘭航空經**都柏林**轉機的獎勵票，並排比較所需 Avios 與飛行時間。這是 Avios.com 繼月曆搜尋之後的又一次改版。

## 一、新功能重點

| 項目 | 內容 |
| --- | --- |
| 新功能 | **轉機行程**獎勵票搜尋 |
| 轉機點 | 英航 **倫敦希斯洛**、伊比利亞 **馬德里**、愛爾蘭航空 **都柏林** |
| 顯示資訊 | **總飛行時間、轉機時間、Avios 價格**並排比較 |
| 限制 | 目前只限**同一家航空公司**轉機（例如英航接英航） |
| 未來 | 計畫開放三家航空**混搭** |
| 訂位 | 選好後導到**營運航空公司官網**完成 |
| 直飛篩選 | 可勾選「**Show Direct Only**」只看直飛 |

## 二、怎麼用？

1. 到 Avios.com 的「Find Reward Flights」頁面。
2. 輸入出發地、目的地、日期、人數，按搜尋。
3. 右側會列出英航、伊比利亞、愛爾蘭航空的選項。
4. 選擇最適合的行程，導到該航空官網訂位。

## 三、實際搜尋範例

| 行程（紐約 → 羅馬，單程） | 航空 | 轉機點 | 艙等 |
| --- | --- | --- | --- |
| 選項 1 | 英航 | 倫敦 | 商務艙 |
| 選項 2 | 愛爾蘭航空 | 都柏林 | 經濟艙 |
| 選項 3 | 伊比利亞 | 馬德里 | 經濟艙 |

以前要分別到三家官網查，現在一次就能比價。

## 四、Avios.com 近期改版

| 改版 | 內容 |
| --- | --- |
| 先前 | 新增**月曆檢視**，一次看整月獎勵位 |
| **這次** | 新增**轉機行程**搜尋 |
| 未來 | 三家航空混搭轉機 |

## 五、總結

**Avios.com 現在可以一次搜英航倫敦、伊比利亞馬德里、愛爾蘭航空都柏林的轉機獎勵票，並排比較 Avios 與時間，目前限同一家航空轉機。** 用 Avios 飛歐洲的人，查位會方便很多。
