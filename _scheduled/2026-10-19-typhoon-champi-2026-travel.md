# 強颱薔琵 10/23～24 最接近台灣！光復節連假要搭機的人先看：警報時程、航班異動與改退票、不便險

**新聞分類：航空資訊**
**發布日期：2026 年 10 月 19 日**
**最接近台灣：2026 年 10 月 23～24 日**

第 29 號颱風**薔琵（CHAMPI）**已經增強為**強烈颱風**，預計 **10 月 23 日（五）到 24 日（六）最接近台灣**，正好遇上 **10/24～10/26 光復節連假**。

路徑可能登陸，也可能從東部外海北上，目前還有不確定性。連假要出國、搭國內線或去離島的人，這幾天要特別留意航班動態。

## 一、颱風現況（10/19 凌晨 2 點）

| 項目 | 數據 |
| --- | --- |
| 強度 | 強烈颱風 |
| 中心氣壓 | 925 百帕 |
| 近中心最大風速 | 每秒 51 公尺（約 16 級） |
| 七級風暴風半徑 | 平均 200 公里，10/19 晚間預計擴大到 280 公里 |
| 十級風暴風半徑 | 平均 100 公里 |
| 移動方向 | 向西北西，時速約 19～22 公里 |

- **強度巔峰：** 預計 10/20 清晨達到最強，近中心最大風速每秒 60 公尺（約 17 級）。
- **接近台灣時：** 可能受乾空氣影響稍微減弱，但仍有颱風等級的風雨。

## 二、警報與影響時程

| 日期 | 預測 |
| --- | --- |
| 10/21（三）晚間～10/22（四）白天 | 最快發布海上颱風警報 |
| 10/22（四）晚間～10/23（五） | 可能發布陸上颱風警報 |
| 10/23（五） | 影響最明顯，北部、宜蘭、花蓮局部豪雨 |
| 10/24（六） | 持續影響，連假第一天全台有雨 |
| 10/25（日） | 颱風遠離，水氣仍多 |
| 10/26（一） | 東北季風南下，北部、東北部轉涼 |

- **路徑預測：** 10/23 凌晨在台灣東方海面，之後轉向北北西，10/24 凌晨預測位置在宜蘭東方、八重山群島（石垣島）附近海域。
- **海象：** 10/21～10/24 風浪明顯變大，浪高 4 公尺以上；東半部、恆春半島、蘭嶼、綠島 10/20 起要注意長浪。

## 三、暴風侵襲機率

10/19 凌晨的 120 小時暴風侵襲機率（未來 5 天受七級風影響的機率）：

| 地區 | 機率 |
| --- | --- |
| 基隆、宜蘭 | 52% |
| 台北、花蓮 | 50% |
| 新北 | 49% |
| 桃園 | 48% |
| 新竹、綠島 | 45% |
| 台中 | 40% |
| 高雄 | 29% |
| 澎湖 | 23% |
| 金門 | 16% |

- **不是登陸機率：** 這是受七級風影響的機率，不代表登陸位置，也不是放颱風假的依據。
- **桃園機場在高風險區：** 桃園的機率接近 5 成，10/23～10/24 進出桃園的航班要特別留意。

## 四、對航班可能的影響

- **航空公司尚未公告：** 截至 10/19 上午，各航空公司還沒有公布薔琵颱風的航班異動或免費改退票措施，通常會在警報發布前後公告。
- **最可能受影響：** 10/23～10/24 進出桃園、松山、宜蘭花蓮方向的航班，以及離島航線、台灣往返沖繩、石垣島的航班與船班。
- **出國旅客也要看目的地：** 颱風北上路徑經過八重山、沖繩一帶，連假去沖繩、石垣島的人，去程和回程都可能受影響。

## 五、連假要搭機的人該怎麼做？

1. **下載航空公司 App、開推播：** 航班取消或改時間，App 和簡訊通常最快通知。
2. **等颱風專案再改票：** 航空公司公告颱風專案後，會寫明適用的搭乘日期與航班，符合條件才能免費改期或退票；自行提早改票可能要付手續費。
3. **旅遊不便險現在才買通常不賠：** 多數保單規定，颱風已經生成或警報發布後才投保，因這個颱風造成的延誤或取消不在保障範圍，以各保單條款為準。
4. **確認信用卡旅遊險：** 用信用卡刷機票的人，可以查卡片附帶的班機延誤、行程取消保障，留好延誤證明和收據。
5. **用哩程開的獎勵機票：** 颱風專案多半也適用哩程獎勵機票，實際以各航空公司公告為準。
6. **離島旅客多留一天緩衝：** 連假去金門、澎湖、馬祖或外島的人，回程可以預留彈性，船班受浪況影響比飛機更大。

## 六、總結

**強烈颱風薔琵預計 10 月 23～24 日最接近台灣，海上警報最快 10/21 晚間發布，北北基桃宜花暴風侵襲機率約 5 成，正好遇上光復節連假。** 連假要搭機的人先開好航空公司 App 通知，等颱風專案公告再改票；旅遊不便險現在才買通常不保這個颱風，出發前確認信用卡附帶的旅遊保障。
