# 達美傳將開西雅圖－新加坡，12 月初宣布、最快 2027 年秋天開航：8,070 英里，達美第三長航線

**新聞分類：航空資訊／天合聯盟**
**發布日期：2026 年 11 月 26 日**

**達美航空**預計 12 月初在西雅圖辦活動，外界預料將宣布**西雅圖－新加坡**新航線，最快 **2027 年秋天**開航。目前還沒經達美正式證實。

## 一、目前知道的

| 項目 | 內容 |
| --- | --- |
| 確認回新加坡 | 達美商務長 2026 年 8 月公開確認 |
| 出發地 | 排除洛杉磯，外界推測是**西雅圖** |
| 宣布時間 | 預料 **12 月初**在西雅圖的活動 |
| 開航 | 最快 **2027 年秋天** |
| 航距 | 約 **8,070 英里** |
| 排名 | 達美**第三長**航線，僅次於亞特蘭大－開普敦、約翰尼斯堡 |
| 機型 | 可能用新的 A350-1000（推測） |

達美上一次飛新加坡是 2019 年，當時是從日本延伸的亞洲內航線。

## 二、達美的亞洲擴張

| 航點 | 狀態 |
| --- | --- |
| 香港 | 已開航 |
| 馬尼拉、東京成田 | 已宣布 |
| 首爾仁川 | 想從洛杉磯、紐約飛大韓的樞紐 |
| 利雅德 | 原訂開航，已延後 |
| **新加坡** | 預料 12 月宣布 |

## 三、競爭

| 航線 | 目前 |
| --- | --- |
| 西雅圖－新加坡 | 只有新航 |
| 洛杉磯－新加坡 | 只有新航（班次更多） |

達美在西雅圖是第二大，阿拉斯加航空最大；聯航在舊金山的亞洲樞紐比達美的洛杉磯、西雅圖都大。

## 四、總結

**達美 12 月初預料宣布西雅圖－新加坡，最快 2027 年秋天開航，8,070 英里是達美第三長航線。** 這是達美近年亞洲擴張的一部分，正式時程以達美公布為準。
