# 美國 FAA 全國停飛 4 小時！空管通訊故障，近 5,000 班取消、上萬班延誤，交通部長：老舊系統出問題

**新聞分類：航空資訊／無聯盟**
**發布日期：2026 年 11 月 14 日**

**美國聯邦航空總署（FAA）**在 **2026 年 11 月 13 日**美東時間下午因**全美航路管制中心通訊故障**，下令**全國所有機場停止起飛**，停飛超過 **4 小時**。這是 911 之後美國最大規模的空中交通中斷之一，近 **5,000 班取消**、上萬班延誤，週末仍會持續受影響。

## 一、事件時間軸

| 美東時間 | 台灣時間 | 事件 |
| --- | --- | --- |
| 11/13 約 15:15 | 11/14 04:15 | 波士頓、紐約、芝加哥航路管制中心陸續失去多個無線電頻率 |
| **11/13 15:54** | **11/14 04:54** | **FAA 下令全國停飛**，所有出發航班停在地面 |
| 11/13 19:00 | 11/14 08:00 | 美西飛往夏威夷、跨太平洋航班開始放行 |
| **11/13 20:15** | **11/14 09:15** | **全國停飛令解除** |
| 11/14～週末 | － | 航班陸續恢復，仍大量取消、延誤 |

## 二、停飛期間怎麼處理？

| 項目 | 內容 |
| --- | --- |
| 出發航班 | **全部停在地面** |
| 空中航班 | 可以**繼續飛往目的地**，不是強迫就近降落 |
| 國際航班 | 進出美國的國際航班**個案處理** |
| 原因說明 | FAA 稱「特殊情況、基於安全考量」 |

## 三、影響規模

| 項目 | 數字 |
| --- | --- |
| 停飛時間 | **4 小時 21 分** |
| 取消航班 | 近 **5,000 班**（報導數字約 4,700～5,000） |
| 延誤航班 | **上萬班** |
| 停飛當下在空中的飛機 | 據報導逾 3,500 架 |
| 國泰 | 兩班美國出發航班延誤 |
| 加拿大 | 多倫多、蒙特婁機場一度暫停飛美國航班 |

## 四、原因是什麼？

| 官員 | 說法 |
| --- | --- |
| **交通部長杜菲（Sean Duffy）** | 美國空管系統「非常老舊」，是「**老舊網路問題**」、「**舊的交換器和路由器**」 |
| **國土安全部長穆林（Markwayne Mullin）** | 「目前沒有完全確定」，但**沒有任何惡意攻擊或 AI 失控的證據**；暗示是**新設備讓舊系統負荷過大** |
| 同時期 | FAA 本週開始全國導入新的 AI 空管工具 SMART，是否相關尚未確認 |

_同一天微軟也發生全球服務當機，微軟否認與美國停飛有關。_

## 五、後續：白宮要錢升級空管

| 項目 | 內容 |
| --- | --- |
| 白宮 | 敦促國會撥款約 **300 億美元**升級航空基礎設施 |
| 交通部長 | 要求約 **500 億美元**避免 FAA 再出重大問題 |

## 六、這幾天要去美國的台灣旅客怎麼辦？

- 台灣直飛美國的航班多由國籍航空與美國航空公司營運，**出發前先查航空公司 App 或官網**的最新航班狀態。
- 要在美國**轉國內線**的人，週末可能遇到大量取消、班機客滿，預留更多轉機時間。
- 航班取消時，可以要求航空公司**改搭其他航班或退款**；空管問題屬於航空公司無法控制的因素，餐食、住宿補償依各航空規定。

## 七、總結

**FAA 11/13 因全美航路管制通訊故障下令全國停飛逾 4 小時，近 5,000 班取消、上萬班延誤，官方說是老舊網路設備問題、沒有攻擊證據。** 停飛令已解除，但週末美國航班仍會很亂，要去美國或在美國轉機的人出發前務必確認航班。
