# 美國運通兩項權益變動：美國簽帳卡 2027/2/1 起自動開啟 Pay Over Time；英國白金卡 2028 年起 Priority Pass 只剩每年 20 次

**新聞分類：信用卡／美國信用卡**
**發布日期：2026 年 11 月 4 日**

**美國運通**這週有兩項權益變動：**美國簽帳卡**的 **Pay Over Time** 將在 2027 年 2 月 1 日起自動開啟；**英國白金卡**的 **Priority Pass** 則從 2028 年起不再無限次。台灣的美國運通簽帳白金卡不在這兩項變動範圍內，但台灣白金卡的健身禮遇也將在今年底屆滿，可以參考[白金專屬健身禮遇 12/31 屆滿](/amex-platinum-taiwan-gym-benefit-ends-2027)。

## 一、美國：Pay Over Time 自動開啟

| 項目 | 內容 |
| --- | --- |
| 生效日 | **2027/2/1** |
| 適用 | 有 Pay Over Time 功能的美國簽帳卡帳戶（沒有預設消費上限的卡） |
| 變化 | Pay Over Time 會被**設為開啟** |
| 結果 | 帳單多一個「**最低應繳金額**」選項 |
| 全額繳清 | 仍然可以，每月全額繳清就不會有利息 |
| 能否關閉 | 通知沒有說明之後能不能自行關閉 |

### 為什麼很多人在意

| 過去 | 之後 |
| --- | --- |
| Pay Over Time 是選擇性功能 | 自動開啟 |
| Amex 常以 **1 萬點以上 Membership Rewards** 鼓勵卡友開啟 | 自動開啟後，這類獎勵可能就不再出現 |
| 簽帳卡原本必須每月全額繳清 | 開啟後可以只繳最低金額、剩下計息 |

**提醒：** 只繳最低應繳金額會產生高額利息，建議維持每月全額繳清。

## 二、英國：白金卡 Priority Pass 縮水

| 項目 | 2026～2027 年 | 2028/1/1 起 |
| --- | --- | --- |
| 正卡 | 無限次 | **每年 20 次** |
| 附卡 | 無限次 | **每年 10 次** |
| 同行者 | 依現行規定 | 20 次不含同行者 |
| 保留無限次 | — | **2027 年刷滿 3 萬英鎊**，2028 年維持無限次＋1 位同行 |
| Priority Pass 預約 | 2027 年仍有 8 次免費預約 | — |
| 其他貴賓室 | 不受影響 | 不受影響 |

**計算時間：** 3 萬英鎊的消費從 **2027/1/1** 開始計算，次數限制從 **2028/1/1** 開始。

## 三、對台灣讀者的影響

| 卡片 | 影響 |
| --- | --- |
| 美國發行的 Amex 簽帳卡 | Pay Over Time 2027/2/1 起自動開啟 |
| 英國發行的白金卡 | 2028 年起 Priority Pass 限次 |
| 台灣發行的美國運通卡 | 這兩項都不影響；但白金專屬健身禮遇 12/31 屆滿 |

## 四、總結

**美國運通美國簽帳卡 2027/2/1 起自動開啟 Pay Over Time，英國白金卡 2028/1/1 起 Priority Pass 改成正卡每年 20 次、附卡 10 次，2027 年刷滿 3 萬英鎊才能保留無限次。** 兩項都不影響台灣發行的卡，但可以看出各地美國運通都在縮減權益。
