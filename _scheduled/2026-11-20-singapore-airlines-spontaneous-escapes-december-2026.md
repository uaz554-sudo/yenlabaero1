# 新航 12 月 Spontaneous Escapes 獎勵票 7 折：豪經新加坡飛舊金山 55,300 哩、商務艙飛曼谷 17,500 哩，11/30 前訂

**新聞分類：哩程資訊／星空聯盟**
**發布日期：2026 年 11 月 20 日**

**新加坡航空 KrisFlyer** 公布 **12 月 Spontaneous Escapes**：指定航線獎勵票 **7 折**，**11 月 30 日前**訂、**12 月 1～31 日**搭。這個月特別的是**豪華經濟艙**有好幾條美國航線。

## 一、活動重點

| 項目 | 內容 |
| --- | --- |
| 折扣 | 獎勵票 **7 折** |
| 訂位期限 | **2026/11/30** |
| 搭乘期間 | **2026/12/1～12/31** |
| 航線數 | **74 條**（11 月是 107 條） |
| 訂位 | **只能在新航官網或 App**，選「Promo」欄位 |
| 改退 | **不能改、不能退** |
| 酷航 | 另有酷航經濟艙 85 折 |

## 二、豪華經濟艙（單程）

| 航線 | 平常 | 活動價 |
| --- | --- | --- |
| **法蘭克福－紐約** | － | **39,900 哩** |
| **新加坡－舊金山** | 79,000 哩 | **55,300 哩** |
| **成田－洛杉磯** | － | **56,350 哩** |
| **新加坡－紐約（JFK、紐華克）** | 84,500 哩 | **59,150 哩** |
| 新加坡－阿姆斯特丹、慕尼黑、巴黎 | 74,500 哩 | 52,150 哩 |
| 新加坡－布魯塞爾、法蘭克福、米蘭（雙向） | 74,500 哩 | 52,150 哩 |

新加坡飛紐約是世界最長航線之一，用 A350-900ULR 飛。

## 三、商務艙（單程）

| 航線 | 平常 | 活動價 |
| --- | --- | --- |
| 新加坡－峇里島（單向） | 22,000 哩 | **15,400 哩** |
| 新加坡－雅加達、吉隆坡、泗水 | － | 15,400 哩 |
| **新加坡－曼谷、普吉、胡志明市（雙向）** | 25,000 哩 | **17,500 哩** |
| 新加坡－馬尼拉、金邊 | － | 17,500 哩 |
| 新加坡－達卡 | － | 31,500 哩 |
| 新加坡－阿德雷德、墨爾本、西雪梨 | 72,000 哩 | **50,400 哩** |

西雪梨機場是雪梨新開的第二個國際機場，新航 11/23 首航，**12/1～12/24 商務艙全部是黑名單日期**。

## 四、經濟艙（單程，部分）

| 航線 | 活動價 |
| --- | --- |
| 新加坡 → 峇里島 | 5,600 哩 |
| 新加坡－曼谷、普吉 | 9,100 哩 |
| 新加坡 → 澳洲阿德雷德、布里斯本、凱恩斯、墨爾本、雪梨 | 20,300 哩 |
| 新加坡 → 阿姆斯特丹、哥本哈根、倫敦、慕尼黑、巴黎 | 30,800 哩 |
| 法蘭克福－紐約 | 19,250 哩 |
| 新加坡－洛杉磯、西雅圖 | 30,800 哩 |

## 五、要注意的地方

| 項目 | 說明 |
| --- | --- |
| 黑名單日期 | 12 月旺季，平均每條航線商務艙 12.7 天、豪經 20.1 天、經濟艙 14 天不能訂 |
| 聖誕節 | 74 條裡有 47 條聖誕節當天可以出發 |
| 單向 | 部分航線只有單一方向打折 |
| 指定航班 | 有些限定航班號 |
| 不能改退 | 確定會去才訂 |
| 台灣 | 這次整理的名單沒有看到台北航線，完整名單以新航官網為準 |

## 六、誰適合？

| 情況 | 建議 |
| --- | --- |
| 12 月要從新加坡飛美國 | 豪經 55,300～59,150 哩，比經濟艙舒服很多 |
| 12 月在新加坡轉機去東南亞 | 商務艙 15,400～17,500 哩 |
| 行程還不確定 | 不要訂，不能改退 |

## 七、總結

**新航 12 月 Spontaneous Escapes 7 折，11/30 前訂：豪經新加坡飛舊金山 55,300 哩、紐約 59,150 哩、成田飛洛杉磯 56,350 哩；商務艙新加坡飛曼谷、胡志明 17,500 哩。** 12 月黑名單日期多、訂了不能改退，適合已經確定 12 月行程的人。
