# 伊比利亞航空 A321XLR 全數裝好 Starlink！馬德里飛紐約、波士頓、華盛頓等航線，A330、A350 也陸續安裝

**新聞分類：航空資訊／寰宇一家**
**發布日期：2026 年 11 月 14 日**

**伊比利亞航空**旗下 **A321XLR 全部完成 Starlink** 高速 Wi-Fi 安裝。這批單走道長程機主要飛**馬德里往返美洲**，部分 **A330、A350** 廣體機也已經裝好 Starlink。

## 一、重點整理

| 項目 | 內容 |
| --- | --- |
| 完成 | **所有 A321XLR** 都已安裝 Starlink |
| 廣體機 | 部分 **A330、A350** 已安裝，持續擴大 |
| 效果 | 機上上網像在家一樣，可工作、串流、社群 |

## 二、A321XLR 飛哪裡？

| 航線（馬德里出發） | 地區 |
| --- | --- |
| 波士頓（BOS） | 美國 |
| 紐華克（EWR） | 美國 |
| 紐約甘迺迪（JFK） | 美國 |
| 華盛頓杜勒斯（IAD） | 美國 |
| 聖胡安（SJU） | 波多黎各 |

## 三、伊比利亞其他升級

| 項目 | 內容 |
| --- | --- |
| AI 客服 | 部分客服功能導入 AI |
| 餐飲 | 機上餐飲升級 |
| 客艙 | 啟動客艙翻新計畫 |
| 貴賓室 | 馬德里巴拉哈斯機場 **T4 新 Emerald Sorolla 貴賓室** |

## 四、Starlink 航空公司越來越多

| 航空公司 | Starlink 狀態 |
| --- | --- |
| **伊比利亞** | A321XLR 全數完成，廣體機陸續安裝 |
| 漢莎集團 | 首架 A350-1000 起裝 Starlink，Miles & More 會員免費 |
| 聯合航空 | 執行長稱 Starlink 是公司百年來最大優勢之一 |

## 五、總結

**伊比利亞 A321XLR 全數裝好 Starlink，馬德里飛波士頓、紐約、華盛頓等美洲航線都能高速上網，A330、A350 也陸續安裝。** 搭伊比利亞跨大西洋的人，訂位時可以留意是不是 A321XLR 執飛。
