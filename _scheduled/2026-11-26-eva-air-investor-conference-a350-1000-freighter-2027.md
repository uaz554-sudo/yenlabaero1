# 長榮航法說會：明年首架 A350-1000、777 客改貨 Q2 上線，20 架客機全艙等改裝延到明年，待交新機 57 架

**新聞分類：航空資訊／星空聯盟**
**發布日期：2026 年 11 月 26 日**

**長榮航空** 11 月 25 日舉行線上法說會。重點有三個：明年迎來**首架 A350-1000**、**777 客改貨**首架明年第二季上線，以及 **20 架客機全艙等改裝**因座椅認證延到明年。

## 一、航網與運能

| 項目 | 內容 |
| --- | --- |
| 新航點 | **12 月 1 日開航印度德里**；華盛頓、德里效益逐步發酵 |
| 2027 年第一季航網 | 每週 **598 班、53 個航點**（2026 年同期 579 班、51 個航點） |
| 客運運能 | 年增約 **3%** |
| 貨機 | 每週 58 班、20 個航點，運能增 0.3% |
| 票價 | 長程線可望穩健；短程線看各區域需求 |

## 二、機隊

| 項目 | 內容 |
| --- | --- |
| 2027 年交機 | **737-9、A350-1000 各 1 架** |
| 機隊數 | 今年 89 架 → 明年底 **91 架** |
| 待交新機 | **57 架**：A350-1000 24 架、A321neo 22 架、787 系列 11 架 |
| 全部交完 | 2033 年前 |

## 三、客艙改裝延到明年

| 項目 | 內容 |
| --- | --- |
| 規模 | **20 架**客機全艙等改裝 |
| 原訂 | 今年 |
| 延後原因 | 航空供應鏈、飛機座椅認證 |
| 新時程 | 2027 年開始，**2028 年前**全部完成 |

## 四、貨運：777 客改貨

| 項目 | 內容 |
| --- | --- |
| 專案 | 3 架 777 客改貨 |
| 首架 | 11 月中進廠，**2027 年第二季**上線 |
| 全貨機 | 上線後增至 **10 架**，2028、2029 年各再加 1 架 |
| 第四季 | AI 伺服器出貨強，貨運營收值得期待 |

## 五、財務與油價

| 項目 | 內容 |
| --- | --- |
| 前三季稅後純益 | 189.15 億元，EPS 3.5 元 |
| 今年前三季燃油均價 | 每桶 138.2 美元，年增 57% |
| 燃油避險 | 約 10% |
| 明年油價預估 | 每桶約 **140 美元** |

## 六、總結

**長榮航明年迎首架 A350-1000，機隊從 89 架到 91 架，待交新機 57 架 2033 年前交完；20 架客機全艙等改裝延到明年、2028 年前完成；777 客改貨首架明年第二季上線。** 明年第一季每週 598 班、53 個航點，客運運能增 3%，12 月 1 日開航印度德里。
