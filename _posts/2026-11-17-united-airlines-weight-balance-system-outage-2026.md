# 聯合航空系統當機！載重平衡系統故障，全美主線航班停在登機門約 1 小時、418 班延誤，FAA 停飛後才 3 天

**新聞分類：航空資訊／星空聯盟**
**發布日期：2026 年 11 月 17 日**

美國航空業這週真的不平靜。**聯合航空**在美東時間 **11 月 16 日**（週一）傍晚發生**大規模系統中斷**，計算飛機**重量與平衡**的系統故障，全美**主線出發航班全部停在登機門**，大約 1 小時後才恢復。這距離 FAA 全國停飛只有 3 天。

## 一、事件經過

| 項目 | 內容 |
| --- | --- |
| 時間 | 美東 **11/16 傍晚**，**18:00 前**恢復（台灣 11/17 清晨） |
| 故障系統 | 計算飛機**重量與平衡（載重）**的系統 |
| 影響 | 機師拿不到載重資料，**主線出發航班停在登機門** |
| 持續時間 | 約 **1 小時** |
| 延誤 | FlightAware 統計當天傍晚 **418 班**延誤 |
| 不受影響 | **已經在空中**的航班、**United Express** 區域航班 |
| 原因 | 聯航：「**沒有網路攻擊的跡象**」 |

聯航在 X 上道歉，表示團隊正努力恢復運作，恢復後仍提醒旅客當晚可能有延誤。

## 二、為什麼載重系統當機飛機就不能飛？

| 項目 | 說明 |
| --- | --- |
| 載重平衡 | 起飛前要算出旅客、行李、貨物、燃油的重量與分布 |
| 用途 | 決定起飛性能、配平，確保安全 |
| 已在空中的班機 | 起飛前已算好，所以不受影響 |
| United Express | 由區域航空公司營運，用不同系統，所以照飛 |

## 三、這幾天美國接連出狀況

| 日期（美東） | 事件 |
| --- | --- |
| 11/12 | 微軟 Outlook 大規模異常 |
| **11/13** | **FAA 全國停飛**：承包商換光纖時路由器出問題，兩天取消逾 1.4 萬班 |
| 11/16 | 摩根大通、美國銀行、富國銀行等**網銀登入異常** |
| **11/16** | **聯合航空載重系統當機** |

聯航表示，這次故障和銀行當機、FAA 停飛**都沒有關係**。FAA 停飛事件可以看 [美國停飛第二天](/faa-ground-stop-day-two-recovery-l3harris-2026)。

## 四、搭聯航的台灣旅客

- 聯航有台北直飛舊金山的航班，這次只影響**美國出發**的主線航班約 1 小時。
- 在美國**轉聯航國內線**的人，遇到延誤可以用 **United App** 自己改票。
- 航班取消或重大延誤選擇不搭，可以要求退款到原付款方式。

## 五、總結

**聯航 11/16 傍晚載重平衡系統當機，全美主線出發航班停在登機門約 1 小時、418 班延誤，空中航班和 United Express 不受影響，聯航排除網路攻擊。** 美國這週先後遇到 FAA 停飛、銀行當機和聯航系統故障，近期在美國轉機的人多預留時間。
