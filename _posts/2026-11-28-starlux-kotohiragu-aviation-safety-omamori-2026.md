# 星宇 × 香川金刀比羅宮聯名「航空安全御守」：融入高松機場跑道設計，一個 1,000 日圓，11/25 開賣

**新聞分類：航空資訊／無聯盟**
**發布日期：2026 年 11 月 28 日**

日本香川縣琴平町的**金刀比羅宮**和**星宇航空**聯名，推出祈求航空安全的「**航空安全御守**」，**11 月 25 日**起開賣，一個 **1,000 日圓**。

## 一、御守資訊

| 項目 | 內容 |
| --- | --- |
| 名稱 | 航空安全御守 |
| 開賣 | **2026/11/25** |
| 價格 | **1,000 日圓** |
| 地點 | 金刀比羅宮 |
| 材質 | 壓克力 |
| 設計 | 高松機場跑道、天空、金刀比羅宮社紋 |
| 意義 | 金刀比羅宮**第一次**和交通運輸公司合作製作御守 |

金刀比羅宮表示，製作的初衷是「無論是海、空還是飛機，都想守護大家的安全」。

## 二、金刀比羅宮是什麼地方？

| 項目 | 內容 |
| --- | --- |
| 位置 | 香川縣琴平町 |
| 地位 | 四國最具代表性的景點之一 |
| 特色 | 自古以來是守護航海安全的神社 |

## 三、怎麼去？

| 項目 | 內容 |
| --- | --- |
| 航線 | 星宇**台中－高松** |
| 班次 | 每週 5 個來回 |
| 到琴平 | 從高松市區搭電車可到琴平 |

星宇在台中的航點還有名古屋、宮古島等，中部旅客不用再跑桃園。

## 四、總結

**金刀比羅宮和星宇聯名推出「航空安全御守」，11/25 開賣、一個 1,000 日圓，設計融入高松機場跑道，是金刀比羅宮第一次和交通公司合作。** 搭星宇台中－高松去四國，可以順道去琴平請一個。
