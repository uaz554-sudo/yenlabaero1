# 漢莎要在法蘭克福、慕尼黑裁 1,000 人，主品牌短程線大縮編；機師工會限期今天 11/23，可能再罷工

**新聞分類：航空資訊／星空聯盟**
**發布日期：2026 年 11 月 23 日**

**漢莎航空**又有大動作：內部信件曝光，法蘭克福、慕尼黑兩大樞紐約 **1,000 個職位**將被裁；管理層還向監事會提案，**大幅縮減漢莎主品牌的短程航班**。同一時間，機師工會給漢莎的期限就是**今天 11 月 23 日**。

## 一、裁員重點

| 項目 | 內容 |
| --- | --- |
| 規模 | 約 **1,000 個職位** |
| 地點 | **法蘭克福、慕尼黑**兩大樞紐 |
| 範圍 | 只限漢莎主品牌（Deutsche Lufthansa），不含奧地利、布魯塞爾、瑞士、歐洲之翼 |
| 機隊 | 短程線改用較小的 **A220**，取代 A320 |
| 原因 | 中東戰事、燃油成本高、今年 9 天罷工、成本基礎過高 |

內部信件寫道：「轉型兩年後，我們必須承認原本的措施已經不足以確保未來。」

## 二、主品牌可能大縮編

| 項目 | 內容 |
| --- | --- |
| 現有機隊 | 主品牌 **260 多架**，另有 120 多架訂單 |
| 提案之一 | 主品牌只保留**長程 100 架、短程 100 架** |
| 其餘飛機 | 交給成本較低的 **Lufthansa City Airlines** |
| 最激進方案 | 主品牌只飛長程、完全放棄短程（可能性較低，需要好幾年） |

漢莎 2017 年曾保證機師最少 325 架機隊，但 2021 年底終止了這個協議。

## 三、漢莎主品牌為什麼要省？

**2025 年利潤率比較：**

| 航空公司 | 利潤率 |
| --- | --- |
| 英航 | 15.2% |
| 瑞安航空 | 11% |
| 瑞士航空 | 9.3% |
| 法航 | 6.7% |
| 歐洲之翼 | 4.3% |
| 荷航 | 3.2% |
| 布魯塞爾航空 | 1.7% |
| **漢莎主品牌** | **0.9%** |

集團執行長 Carsten Spohr 曾把漢莎主品牌形容為集團的「問題兒童」。

## 四、機師工會的回應

| 項目 | 內容 |
| --- | --- |
| 工會 | Vereinigung Cockpit（VC） |
| 說法 | 裁員消息是「一場威脅的大戲」，時間點「不是巧合」 |
| 期限 | **11/23**，要漢莎接受調解方案 |
| 下一步 | 談不攏可能**再罷工** |

工會說，裁員消息就在他們發出期限通知的隔天公布，是用來向員工施壓。

## 五、荷航也在大裁員

| 項目 | 內容 |
| --- | --- |
| 規模 | 未來幾年裁 **5,000 人**，約 15% |
| 地勤 | 阿姆斯特丹地勤外包 |
| 機隊 | 737 改由子公司用較小的 E195-E2 飛；取消新 A320 訂單 |

## 六、對台灣旅客的影響

| 情況 | 建議 |
| --- | --- |
| 年底經法蘭克福、慕尼黑轉機 | 11/23 後留意是否宣布罷工 |
| 歐洲境內短程 | 以後可能多由 City Airlines 或 A220 執飛 |
| 已買票 | 若罷工取消，依歐盟 EU261 可要求退款或改票 |

先前的機師爭議經過可以參考[漢莎機師工會：調解方案被拒](/lufthansa-pilots-dispute-mediation-rejected-2026)。

## 七、總結

**漢莎要在法蘭克福、慕尼黑裁約 1,000 人，短程改用 A220，並提案把主品牌縮到長程、短程各 100 架，其餘交給 City Airlines。** 漢莎主品牌 2025 年利潤率只有 0.9%，是集團裡最差的。機師工會的期限就是今天 11/23，談不攏可能再罷工，年底要經德國轉機的人請留意。
