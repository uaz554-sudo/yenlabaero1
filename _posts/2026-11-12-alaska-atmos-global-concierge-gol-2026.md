# 阿拉斯加航空推邀請制最高會籍「Atmos Global Concierge」！專屬禮賓、希斯洛轉機接送、升等優先，另新增巴西 GOL 夥伴

**新聞分類：哩程資訊／寰宇一家**
**發布日期：2026 年 11 月 12 日**

**阿拉斯加航空 Atmos Rewards** 推出邀請制最高等級「**Atmos Global Concierge**」，排在 **Titanium 之上**，沒有公開的達成門檻。同時，阿拉斯加新增巴西 **GOL 航空**為 Global Partner。

## 一、Atmos Global Concierge 是什麼？

| 項目 | 內容 |
| --- | --- |
| 等級 | **Titanium 之上**的最高等級 |
| 取得方式 | **只能受邀**，沒有公開門檻 |
| 會籍效期 | 獲邀者到 **2027/12/31** |
| 可能的邀請對象 | 常飛國際線商務艙的高價值旅客 |
| 類似產品 | 美國航空 ConciergeKey、達美 Delta 360、聯合航空 Global Services |

## 二、權益

| 權益 | 內容 |
| --- | --- |
| **專屬禮賓團隊** | 主動監看航班，可**保證下一班機位**，長程抵達時提供協助 |
| **希斯洛轉機接送** | 倫敦希斯洛轉機時間緊時安排**車輛接送** |
| **升等優先** | 優先順序**高於 Titanium**，國際線尤其明顯 |
| 租車會籍 | **Avis Chairman's Club** |
| 機場安檢 | **CLEAR+** 會員 |

## 三、Atmos Rewards 會籍等級

| 等級 | 取得方式 |
| --- | --- |
| Silver、Gold、Platinum、Titanium | 公開門檻，累積卡級點數 |
| **Global Concierge** | **只能受邀** |

## 四、新增 GOL 為 Global Partner

| 項目 | 內容 |
| --- | --- |
| 新夥伴 | **GOL 航空**（巴西，Abra 集團旗下，和哥倫比亞航空同集團） |
| 累積 | 可以**累積** Atmos 點數，目前看來限透過阿拉斯加訂的 GOL 航班 |
| 兌換 | **目前不能用 Atmos 點數兌換** GOL 航班 |

阿拉斯加目前的 Global Partners：

| 航空公司 | 地區 |
| --- | --- |
| 愛爾蘭航空 | 歐洲 |
| 大溪地航空 | 南太平洋 |
| 神鷹航空 | 歐洲 |
| **GOL 航空（新）** | 南美 |
| 海南航空 | 中國 |
| 冰島航空 | 歐洲 |
| 大韓航空 | 亞洲 |
| 菲律賓航空 | 亞洲 |
| **星宇航空** | **台灣** |

## 五、對台灣讀者的意義

- **星宇航空**是阿拉斯加的 Global Partner，常飛星宇美國線、把哩程累積到 Atmos 的人，理論上也是高價值旅客，但 Global Concierge 的邀請條件沒有公開。
- 阿拉斯加明年開**安克拉治－東京成田**，國際線布局持續擴大，邀請制會籍就是為了留住常飛國際線的旅客。

## 六、總結

**阿拉斯加航空推出邀請制最高會籍 Atmos Global Concierge，有專屬禮賓、希斯洛轉機接送、優先升等、Avis 與 CLEAR+ 會籍，獲邀者到 2027 年底；另新增巴西 GOL 為 Global Partner，目前只能累積。** 邀請門檻沒有公開，一般旅客不用特別追求。
