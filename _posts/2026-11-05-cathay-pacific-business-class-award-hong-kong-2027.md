# 國泰商務艙大放位！洛杉磯、舊金山、西雅圖飛香港 2027 年 7～10 月，單程 91,000 亞洲萬里通＋約 208 美元

**新聞分類：哩程資訊／寰宇一家**
**發布日期：2026 年 11 月 5 日**

**國泰航空**美西飛**香港**的**商務艙**開出大量獎勵機位：**洛杉磯、舊金山、西雅圖**出發，**2027 年 7 月到 10 月**，單程只要 **91,000 亞洲萬里通**加約 208 美元稅費。同樣的位子現金票每人超過 **4,500 美元**。

## 一、這次放位

| 項目 | 內容 |
| --- | --- |
| 艙等 | **商務艙** |
| 出發 | **洛杉磯（LAX）、舊金山（SFO）、西雅圖（SEA）** |
| 目的地 | 香港（HKG） |
| 日期 | **2027 年 7 月～10 月** |
| 點數 | **單程 91,000 亞洲萬里通** |
| 稅費 | 約 **208～218 美元**（依出發機場） |
| 現金票 | 每人超過 **4,500 美元** |
| 飛行時間 | 洛杉磯、舊金山出發約 14 小時多 |

*91,000 亞洲萬里通＋208 美元，對比 4,500 美元現金票，每哩約可換到 4.7 美分的價值。*

## 二、怎麼訂

| 管道 | 說明 |
| --- | --- |
| **國泰官網（亞洲萬里通）** | 位子最多，價格 91,000 哩＋稅費 |
| 夥伴計畫 | 部分日期也看得到位子，其中**芬航 Avios** 價格最低 |
| 查位小技巧 | 國泰官網只有「週」檢視，可用 Seats.aero 等工具一次比較多條航線、多個日期 |

芬航 Avios 本週買最高 5 折，可參考[芬航買 Avios 最高 5 折](/finnair-plus-buy-avios-50-off-tier-points-2026)。

## 三、亞洲萬里通從哪來

### 美國信用卡

| 點數 | 轉亞洲萬里通比例 |
| --- | --- |
| Bilt Rewards | 1：1 |
| Capital One | 1：1 |
| Citi ThankYou | 1：1 |
| Rove Miles | 1：1 |
| Amex Membership Rewards | 5：4 |
| Brex Rewards | 3：2 |
| Marriott Bonvoy | 3：1 |

### 台灣

| 方式 | 說明 |
| --- | --- |
| 國泰世華小樹點 | 2027 年起 **390 點換 1,000 亞洲萬里通**，詳見[國泰世華小樹點 2027 換哩程調整](/cathay-cube-tree-points-2027-mileage-ratio) |
| 國泰世華亞洲萬里通聯名卡 | 刷卡直接累積 |

## 四、要注意

- **美國出發**：這次放位是美西飛香港，從台灣出發的人要先到美國。
- **回台灣**：抵達香港後還要另外訂香港－台北的航段。
- **稅費**：從美國出發約 208～218 美元。
- **位子會被搶**：查到就盡快訂，轉點前先確認有位。
- **新頭等艙**：國泰新頭等艙 Halo Suites 最快 2027 年底才會出現，詳見[國泰新頭等艙 Halo Suites](/cathay-pacific-halo-suites-first-class-777-9)。

## 五、總結

**國泰美西三城飛香港商務艙 2027 年 7～10 月大放位，單程 91,000 亞洲萬里通＋約 208 美元，現金票超過 4,500 美元。** 明年暑假要從美國回亞洲的人，可以先查位，用美國卡點數或台灣累積的亞洲萬里通換。
