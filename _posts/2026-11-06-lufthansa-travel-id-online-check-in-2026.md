# 漢莎集團線上報到要先登入 Travel ID！美國出發 11/16、亞洲等其他地區 11/30 起適用，沒帳號只能去機場報到

**新聞分類：航空資訊／星空聯盟**
**發布日期：2026 年 11 月 6 日**

**漢莎集團**正在分階段要求旅客**登入 Travel ID 帳號**才能**線上報到**。從美國出發的航班 **11/16** 起適用，**11/30** 擴大到**亞洲等其他所有地區**和**法蘭克福**，全面上路。沒有帳號的旅客，只能到機場櫃檯或自助報到機報到。

## 一、適用時程

| 開始日期 | 適用的出發地 |
| --- | --- |
| **10/20** | 申根區國家（德國、奧地利、瑞士除外） |
| **11/2** | 非申根歐洲國家；德國（法蘭克福、慕尼黑除外）、奧地利、瑞士（蘇黎世除外） |
| **11/16** | 美國、加拿大、墨西哥；**慕尼黑**、**蘇黎世** |
| **11/30** | **其他所有地區**（含亞洲）；**法蘭克福** |

## 二、適用航空與例外

| 項目 | 內容 |
| --- | --- |
| 適用航空 | **漢莎、瑞士航空、奧地利航空、布魯塞爾航空、Edelweiss、Discover** |
| 例外 1 | 在**機場櫃檯或自助報到機**報到 |
| 例外 2 | **其他航空開票**的機票（例如聯合航空、全日空開票的漢莎航班） |
| 例外 3 | **其他航空執飛**的航班 |

## 三、Travel ID 是什麼？

- **漢莎集團的旅客帳號：** 一個帳號可以登入集團各家航空的官網與 App，管理訂位、報到。
- **和 Miles & More 不同：** Miles & More 是哩程計畫，Travel ID 是登入帳號，兩者分開，但可以連結。
- **免費註冊：** 在漢莎官網或 App 用 Email 註冊即可。

## 四、對台灣旅客的影響

- **從亞洲出發：** 例如從曼谷、香港、東京搭漢莎、瑞航、奧航，11/30 起要線上報到就得先註冊 Travel ID。
- **用星空聯盟夥伴開票：** 例如聯合航空、全日空開票的漢莎航班，屬於「其他航空開票」，目前不受影響。
- **回程從歐洲出發：** 德國、瑞士等地已經開始適用，回程線上報到也要登入。

漢莎最近還有其他規定改變，例如跳段搭乘要申報，可以參考[漢莎跳段搭乘新規](/lufthansa-skip-flight-proof-rule-2026)。

## 五、總結

**漢莎集團 11/30 起全面要求登入 Travel ID 才能線上報到，美國出發 11/16、亞洲與法蘭克福出發 11/30 適用；機場櫃檯報到、其他航空開票或執飛的航班不受影響。** 常搭漢莎集團的人，出發前先用 Email 註冊 Travel ID，並和 Miles & More 帳號連結。
