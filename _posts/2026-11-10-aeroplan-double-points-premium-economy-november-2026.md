# 加航 Aeroplan 點數加倍！11/15 前訂豪經全球航線、6 條經濟艙航線，現金票最高雙倍點數，不用登記

**新聞分類：哩程資訊／星空聯盟**
**發布日期：2026 年 11 月 10 日**

**加拿大航空 Aeroplan** 推出限時現金票加倍點數：**11 月 15 日前**直接向加航訂購符合資格的機票，**豪華經濟艙全球航線**與 **6 條經濟艙指定航線**最高可拿到**雙倍 Aeroplan 點數**，**不用登記**。

## 一、活動重點

| 項目 | 內容 |
| --- | --- |
| 訂位期間 | **2026/11/3～11/15**（11/3 前訂的不適用） |
| 登記 | **不用登記**，自動入帳 |
| 訂購管道 | **直接向加拿大航空**訂現金票 |
| 加倍方式 | 依**基本票價**計算，額外多送 1 倍，最高雙倍點數 |
| 不計點 | 航空公司附加費、稅金與規費不算加贈 |
| 不適用 | **商務艙**、經濟艙 **Basic** 票價 |

## 二、豪華經濟艙：幾乎全球航線

| 加拿大往返 | 搭乘期限 |
| --- | --- |
| 美國 | **2027/3/29 前飛完** |
| 墨西哥 | 同上 |
| 加勒比海 | 同上 |
| 南美洲 | 同上 |
| 歐洲 | 同上 |
| 非洲 | 同上 |
| **亞太（含台灣、日本等）** | 同上 |

## 三、經濟艙：6 條指定航線

| 航線 | 搭乘期限 |
| --- | --- |
| **蒙特婁（YUL）⇄ 艾德蒙頓（YEG）** | **2027/4/30 前飛完** |
| 加拿大 ⇄ **紐華克（EWR）** | 同上 |
| 加拿大 ⇄ **札幌（CTS）** | 同上 |
| 加拿大 ⇄ **基多（UIO）** | 同上 |
| 加拿大 ⇄ **法蘭克福（FRA）** | 同上 |
| 加拿大 ⇄ **巴亞爾塔港（PVR）** | 同上 |

_經濟艙要買 Standard 以上的票價，Basic（基本經濟艙）不適用。_

## 四、對台灣讀者的意義

- **台北－溫哥華豪經：** 加航台北－溫哥華屬於「加拿大往返亞太」，買**豪華經濟艙現金票**就適用加倍；亞太航線豪經一般就能累積不少點數，加倍後更有感。
- **冬天去北海道：** 經濟艙指定航線包含**加拿大－札幌**，住在加拿大、冬天要去北海道滑雪的人可以注意。
- **11/3 前已經訂好的票：** 活動不追溯。如果原本的票可以免費取消，可以考慮取消後重訂，但要先確認票價沒有上漲。

## 五、總結

**加航 Aeroplan 11/15 前訂豪經全球航線（2027/3/29 前飛完）、6 條經濟艙航線（2027/4/30 前飛完），現金票最高雙倍點數，不用登記，商務艙與 Basic 票不適用。** 本來就要買加航豪經的人，這幾天訂最划算。
