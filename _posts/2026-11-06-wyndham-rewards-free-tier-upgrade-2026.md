# 溫德姆 Wyndham Rewards 免費升一級會籍！藍卡、金卡、白金卡 12/30 前登記，鑽石卡送 3,000 點

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 6 日**

**溫德姆 Wyndham Rewards** 的年底會籍升等活動又來了：全球**藍卡、金卡、白金卡**會員只要在 **2026/12/30** 前登記，就能**免費升一個等級**；已經是最高等級的**鑽石會員**，改送 Insider 試用或 **3,000 點**。要注意升上去的會籍**只到 2026/12/31**，等於只有不到兩個月。

## 一、活動內容

| 現在等級 | 可以拿到 |
| --- | --- |
| 藍卡（Blue） | 升 **金卡（Gold）** |
| 金卡（Gold） | 升 **白金卡（Platinum）** |
| 白金卡（Platinum） | 升 **鑽石卡（Diamond）** |
| 鑽石卡，美國會員 | 2 個月 **Wyndham Rewards Insider** 訂閱 |
| 鑽石卡，美國會員且已訂 Insider | **3,000 點** |
| 鑽石卡，美國以外會員 | **3,000 點** |

| 條件 | 內容 |
| --- | --- |
| 登記期間 | 美東時間 **11/5 00:01～12/30 23:59**（台灣 12/31 中午 12:59 前） |
| 登記方式 | 活動 Email 的連結，或溫德姆官網的活動頁 |
| 會籍效期 | 到 **2026/12/31** |
| 次數 | 每位會員限一次 |

## 二、3,000 點能做什麼？

官方說法是 3,000 點足夠在參加的溫德姆飯店，用「點數加現金」兌換一晚折扣房。溫德姆全額點數兌換房從 **7,500 點**起，3,000 點不夠換一整晚，但可以和其他活動的點數累積。

## 三、適合誰？

- **適合：** 11、12 月有溫德姆住宿的人，入住前先登記，就能用高一級的會籍入住。
- **不適合期待長期效益的人：** 會籍到 12/31 就結束，2027 年要繼續維持，還是要靠住宿晚數或聯名卡。
- **台灣會員：** 溫德姆在台灣陸續增加飯店，2027 年還有溫德姆花園、速 8 首度登台，可以參考[溫德姆在台灣一次簽下 4 家飯店](/wyndham-taiwan-four-hotels-wyndham-garden-super-8-2027)。

## 四、總結

**溫德姆藍卡、金卡、白金卡會員 12/30 前登記可免費升一級，鑽石會員送 Insider 或 3,000 點，升等效期只到 12/31。** 登記不用花錢，年底前有溫德姆住宿的人記得先登記再入住。
