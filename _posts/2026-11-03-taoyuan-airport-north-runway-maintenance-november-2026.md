# 桃園機場北跑道 11/3 起夜間歲修！每次凌晨 1:00～6:30、共 7 個工作天，南跑道照常起降

**新聞分類：航空資訊／無聯盟**
**發布日期：2026 年 11 月 3 日**

**桃園機場北跑道 11 月 3 日起進行年度歲修**，針對跑道和滑行道的重點區域做**預防性刨鋪**，預計 **7 個工作天**完成。施工全部排在**凌晨 1:00～6:30** 原本就關閉維護的時段，**南跑道照常運作**，旅客的航班原則上不受影響。

## 一、施工安排

| 項目 | 內容 |
| --- | --- |
| 施工範圍 | 北跑道及滑行道重點區域 |
| 工程內容 | 預防性刨鋪（刨除舊鋪面、重新鋪設） |
| 開始日期 | 2026 年 11 月 3 日 |
| 施工天數 | 預計 **7 個工作天** |
| 每次時段 | **01:00～06:30**，共 5.5 小時 |
| 時段來源 | 原本就有的夜間例行關閉維護時段 |
| 施工日 | 11 月**非週末假日的單數日** |
| 暫緩條件 | 每天施工前評估，**天候不佳或航班較多**時當天暫緩 |
| 另一條跑道 | **南跑道維持正常運作** |

## 二、11 月可施工的日期

符合「非週末假日、單數日」的日子如下，實際施工日以機場當天評估為準：

| 日期 | 星期 | 備註 |
| --- | --- | --- |
| 11/3 | 二 | 第一天 |
| 11/5 | 四 | |
| 11/9 | 一 | |
| 11/11 | 三 | |
| 11/13 | 五 | |
| 11/17 | 二 | |
| 11/19 | 四 | 若前面每天都施工，這天是第 7 天 |
| 11/23 | 一 | 備用 |
| 11/25 | 三 | 備用 |
| 11/27 | 五 | 備用 |

11 月共有 **10 個**符合條件的日子，只要用掉 7 個，所以有 3 天緩衝可以應付天候或航班量太大而暫停的情況。

## 三、桃園機場兩條跑道

| 跑道 | 編號 | 長度 × 寬度 | 歲修期間 |
| --- | --- | --- | --- |
| 北跑道 | 05L/23R | 3,660 × 60 公尺 | 凌晨 1:00～6:30 施工 |
| 南跑道 | 05R/23L | 3,800 × 60 公尺 | **正常起降** |

凌晨 1:00～6:30 本來就是北跑道例行關閉維護的時段，這段時間的起降原本就集中在南跑道，所以歲修不需要另外關閉跑道。

## 四、為什麼要在 11 月做

| 項目 | 內容 |
| --- | --- |
| 例行性 | 跑道歲修**每年都會做** |
| 今年旅運量 | **10 月 13 日突破 4,000 萬人次** |
| 時間點 | 趕在**耶誕跨年、春節**旅運高峰前完成 |
| 事前準備 | 多次邀民航局飛航服務總台、航空公司、地勤公司、施工單位開協調會 |
| 影響評估 | 以**國慶連假疏運的最大航班量**評估營運影響 |
| 施工期間 | 成立專案小組，即時協調 |

## 五、旅客要注意什麼

- **白天、晚上的航班：** 不受影響，施工只在凌晨 1:00～6:30。
- **深夜、清晨航班：** 這段時間所有起降都在南跑道。航班本身照常，但遇到延誤需要排隊起降時，可能比平常多等一下，建議出發前用航空公司 App 或桃園機場官網確認航班動態。
- **施工會不會延期：** 會。每天施工前都會評估，天候不好或航班多就暫停，所以實際完工日可能晚於 11/19。

## 六、總結

**桃園機場北跑道 11 月 3 日起歲修 7 個工作天，每次凌晨 1:00～6:30、只排在 11 月非週末假日的單數日，南跑道照常起降。** 一般旅客幾乎感覺不到影響；搭深夜、清晨班機的人，出門前多看一下航班動態就好。
