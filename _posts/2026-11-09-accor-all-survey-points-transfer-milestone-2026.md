# 雅高 ALL 問卷透露兩項新功能：會員之間轉點、里程碑獎勵！其他集團早就有，雅高想追上嗎？

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 9 日**

**雅高 ALL** 這個週末在 App 對會員發出問卷，詢問兩項可能的新功能：**會員之間轉移點數**，以及**里程碑獎勵（Milestone Rewards）**。這兩項其他大型飯店集團都已經有了。問卷不代表一定會推出，但可以看出雅高可能的方向。

## 一、問卷的兩個重點

| 可能的新功能 | 內容 |
| --- | --- |
| **會員之間轉點** | 問會員會不會在帳戶之間合併點數、原因是什麼；還問了兌換點數的頻率 |
| **里程碑獎勵** | 住滿一定晚數後給額外獎勵 |

- **問卷只在 App 出現：** 目前沒看到 Email 邀請，回覆的多半是比較活躍的會員。

## 二、其他集團怎麼做？

### 轉點

| 集團 | 會員之間轉點 |
| --- | --- |
| 希爾頓 | 可以，**免費** |
| 凱悅 | 可以，**免費**（最近還開放線上操作） |
| 萬豪 | 可以，**免費** |
| IHG | 理論上可以，但要另有 IHG Business Rewards 帳戶 |
| **雅高 ALL** | 只有 **ALL Signature** 會員可以，多半是人工處理 |

### 里程碑獎勵

| 集團 | 里程碑獎勵 |
| --- | --- |
| 凱悅 | **最完整** |
| IHG | 次之 |
| 希爾頓 | 大多是加送點數 |
| 萬豪 | 可選會籍晚數、免費住宿券或慈善捐款 |
| **雅高 ALL** | 目前沒有 |

## 三、雅高現在拿會籍的方式

雅高其實已經有很多「付費」或加碼拿會籍的方法：

| 方式 | 內容 |
| --- | --- |
| ALL Accor+ Explorer、ibis、Voyager | 付費會籍，送會籍晚數 |
| 巴西 ALL Signature | Absolute 等級每月送 1,000 會籍點數 |
| 雅高中國計畫 | 可暫時和上述方案疊加，突破訂閱會籍的 30 晚上限，最多約 50 晚 |
| 會籍晚數加碼活動 | 經常推出 |
| 點數轉會籍點數 | 部分方案可以，或直接買下一級、續會 |

Accor+ Explorer 加送 3,000 點的活動到 11/30，可以參考[雅高 Accor+ Explorer 加送 3,000 點](/accor-plus-explorer-3000-bonus-2026)。

## 四、對會員的意義

- **轉點的實際好處有限：** ALL 點數是**固定價值**，2,000 點折 40 歐元，合併點數主要是方便一起出遊時，用會籍比較高的帳戶訂房。
- **里程碑獎勵最好能讓會員自己選：** 例如選會籍晚數、免費住宿或加送點數。
- 台灣會員折抵點數的門檻，可以參考[雅高 ALL 點數折抵門檻調整](/accor-all-minimum-points-taiwan-500)。

## 五、總結

**雅高 ALL 在 App 問卷詢問會員之間轉點與里程碑獎勵兩項新功能，希爾頓、凱悅、萬豪早就能免費轉點，凱悅、IHG、萬豪、希爾頓也都有里程碑獎勵。** 問卷不代表一定會推出，如果真的上線，再幫大家整理規則。
