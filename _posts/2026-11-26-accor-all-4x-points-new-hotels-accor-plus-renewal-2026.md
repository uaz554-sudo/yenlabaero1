# 雅高 ALL 新飯店住宿 4 倍點數，最多 3 次、2027/1/17 前登錄；ALL Accor+ Explorer 續約送 5,000 點（指定會員）

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 26 日**

**雅高 ALL** 有兩個新活動：入住**新飯店**拿 **4 倍點數**，以及部分 **ALL Accor+ Explorer** 會員收到**續約送 5,000 點**的優惠。

## 一、新飯店 4 倍點數

| 項目 | 內容 |
| --- | --- |
| 獎勵 | 每次入住名單上的新飯店，拿 **4 倍點數** |
| 次數 | 最多 **3 次** |
| 登錄與訂房 | **2027/1/17 前** |
| 入住 | **2027/5/16 前** |
| 入帳 | 退房後 7～10 天 |
| 登錄 | **需要** |
| 名單 | 每 8 週更新 |

**名單上的飯店例子：**

| 飯店 | 地點 |
| --- | --- |
| Greet Hotel Sydney Redfern | 澳洲雪梨 |
| Novotel Brisbane City | 澳洲布里斯本 |
| Peppers Clear Valley、Peppers Clear Mountain | 澳洲 |
| Pullman Antwerp | 比利時安特衛普 |
| Ibis Mogi Guaçu Shopping | 巴西 |

完整名單看活動頁的「Conditions of Sale」。名單會更新，先登錄比較保險。

## 二、ALL Accor+ Explorer 續約送 5,000 點（指定會員）

| 項目 | 內容 |
| --- | --- |
| 對象 | 部分**關閉自動續約**的 Explorer 會員收到 Email |
| 優惠 | 續約送 **5,000 點**（平常 3,000 點，再加 2,000 點） |
| 條件 | 要開啟自動續約，或在會籍到期前續約 |
| 取消 | 會員因故取消，加贈點數作廢 |

先確認自己有沒有收到信；部分關閉自動續約的人也收到 ALL Signature 8 折的續約優惠。

## 三、台灣讀者要知道

**台灣目前沒有雅高飯店。** 4 倍點數活動適合年底到明年上半年要去澳洲、歐洲等地旅行、剛好住到名單上新飯店的人。

## 四、總結

**雅高 ALL 新飯店 4 倍點數活動要登錄，最多 3 次，2027/1/17 前登錄訂房、5/16 前入住；部分關閉自動續約的 ALL Accor+ Explorer 會員可以拿到續約送 5,000 點的優惠。**
