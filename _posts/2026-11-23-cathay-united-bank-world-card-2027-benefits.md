# 國泰世華 2027 世界卡權益公布：刷 2 萬就有 8 次貴賓室、海外最高 3.8%，機場停車門檻 2 萬

**新聞分類：信用卡／台灣信用卡**
**發布日期：2026 年 11 月 23 日**

國泰世華公布 **2027 年度世界卡權益**，期間 **2027 年 1 月 1 日到 12 月 31 日**。貴賓室改成「**帳單新增消費達門檻就有 8 次**」，海外消費回饋最高 **3.8%**。要注意的是，**亞洲萬里通世界卡不適用**這次的權益。

## 一、旅遊權益

### 1. 全球機場貴賓室：上限 8 次

| 條件（擇一） | 權益 |
| --- | --- |
| **當期或前期**信用卡帳單世界卡新增消費達 **NT$2 萬** | 免費使用上限 **8 次** |
| **前三期**帳單（含當期）世界卡新增消費合計達 **NT$6 萬** | 同上 |

進貴賓室要出示有效的 **U.First 電子卡**、本人登機證和護照。

### 2. 機場接送：最多 4 次

| 世界卡一般消費 | 次數 |
| --- | --- |
| 滿 **NT$30 萬** | **2 次**指定區域單趟機場接或送 |
| 滿 **NT$60 萬** | **再 2 次**，共 4 次 |

### 3. 機場外圍免費停車：不限次數

| 項目 | 內容 |
| --- | --- |
| 條件 | 刷世界卡買**國際線機票或國外團費**，單筆滿 **NT$2 萬** |
| 次數 | **不限次數** |
| 天數 | 每次最多 **30 天** |

停車權益的門檻調整，詳見[國泰世華 2027 機場停車權益](/cathay-united-bank-airport-parking-2027)。

## 二、回饋權益

### 1. 海外消費最高 3.8%

| 項目 | 內容 |
| --- | --- |
| 條件 | 世界卡海外消費（含線上、實體）**全年累計滿 NT$80 萬** |
| 加碼 | **2.9%** 小樹點（信用卡） |
| 合計 | 含主權益 0.9%，最高 **3.8%** |
| 上限 | 加碼每戶 **23,200 點** |

加碼上限 23,200 點，等於加碼部分最多算到 80 萬元海外消費。

### 2. 保費最高 1.8%

| 單筆保費 | 加碼 | 含主權益 0.6% |
| --- | --- | --- |
| NT$30 萬～未滿 100 萬 | 0.6% | 1.2% |
| NT$100 萬～未滿 300 萬 | 0.9% | 1.5% |
| **NT$300 萬以上** | **1.2%** | **1.8%** |

加碼每戶上限 **80,000 點**。國泰人壽躉繳保費、投資型、利率變動型年金，以及 2021 年 6 月底前傳統型保單的續期保費不適用。

### 3. 外幣換匯減碼

正卡持卡人每月 **2 次**指定外幣換匯減碼：

| 幣別 | 優惠匯差 |
| --- | --- |
| 美元 | 0.035 |
| 日幣 | 0.0015 |
| 人民幣 | 0.015 |
| 歐元 | 0.1 |
| 澳幣 | 0.04 |

## 三、生活權益

| 權益 | 內容 |
| --- | --- |
| 飯店美饌 | 多家五星酒店、人氣餐廳**最優 2 人 5 折**（以原價計、另收 10% 服務費） |
| 一泊二食 | 指定五星度假酒店獨家優惠 |
| 飯店住宿 | 全台指定飯店優惠價或升等 |
| 專屬訂位 | 每月 11 日 15:00 開放優先訂位：山海樓、亞都麗緻天香樓、承家私廚、MUME、SAAKA、T+T 等（2027/1/1～6/30） |
| 高球 | 世界卡友：老爺關西、揚昇、南峰、信誼、嘉南等；龍潭、美麗華限財富管理鑽石、白金 VIP 與私銀客戶 |
| 麗晶精品 | 單日累計滿 90 萬或年累計滿 160 萬，可申辦麗晶精品黑卡 |

## 四、次年免年費條件

| 2027 年度世界卡消費 | 次年年費 |
| --- | --- |
| **滿 NT$60 萬** | **免年費** |
| 滿 NT$30 萬 | **5 折** |

附卡消費併入正卡計算。

## 五、要注意的地方

| 項目 | 說明 |
| --- | --- |
| 適用卡別 | **不含亞洲萬里通世界卡** |
| 貴賓室 | 看帳單「新增消費」，不是一般消費 |
| 一般消費定義 | 依國泰世華官網公告 |
| 變動 | 銀行可依公告調整 |

## 六、誰適合？

| 情況 | 建議 |
| --- | --- |
| 每月刷 2 萬以上、常出國 | 貴賓室 8 次很實用 |
| 年海外消費接近 80 萬 | 最高 3.8% 回饋 |
| 年消費 60 萬以上 | 免次年年費 |
| 主要想累積亞洲萬里通 | 亞洲萬里通世界卡不適用這次權益 |

## 七、總結

**國泰世華 2027 世界卡：帳單新增消費 2 萬（或三期合計 6 萬）就有 8 次貴賓室，一般消費 30 萬、60 萬各送 2 次機場接送，機場停車單筆 2 萬不限次數；海外全年滿 80 萬最高 3.8%、保費最高 1.8%。** 年消費 60 萬免次年年費。亞洲萬里通世界卡不適用。
