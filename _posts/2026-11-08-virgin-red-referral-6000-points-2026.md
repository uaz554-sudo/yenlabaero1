# Virgin Red 推薦註冊雙方各送 6,000 點！11/30 前註冊、18 個月內完成一筆交易，綁定 Tesco 再拿 2,500 點

**新聞分類：哩程資訊／無聯盟**
**發布日期：2026 年 11 月 8 日**

**Virgin Red** 推出推薦活動：**11/3～11/30** 透過推薦連結**新註冊** Virgin Red，被推薦的人完成第一筆累積交易後，**雙方各得 6,000 Virgin Points**。註冊後再到 App 綁定英國超市 **Tesco** 的會員，還能多拿 **2,500 點**。

> **官方條款重點：** ① 推薦人每 12 個月最多拿 **10 次**推薦獎勵；② 被推薦人要在加入後 **18 個月內**完成第一筆符合資格的交易，點數才會入帳；③ 官方限 **18 歲以上英國居民**。

## 一、Virgin Red 和維珍航空會員有什麼不同？

| 項目 | Virgin Red | Virgin Atlantic Flying Club |
| --- | --- | --- |
| 性質 | 維珍集團的生活點數 App | 維珍航空的哩程計畫（大家說的「維珍航空會員」） |
| 點數 | **Virgin Points** | **Virgin Points**（同一種點數） |
| 誰會有帳號 | 兌換過郵輪等維珍集團商品的人 | 一般累積、兌換機票的人 |
| 這次活動 | ✅ 新註冊才有 | ❌ 不適用 |

- 一般人通常只有維珍航空 Flying Club 帳號；**沒註冊過 Virgin Red 的人，這次可以拿到新會員獎勵**。
- 兩邊的點數可以互相移轉；要兌換維珍郵輪，必須從 Virgin Red 兌換。

## 二、推薦活動規則（Virgin Red 官網）

| 項目 | 內容 |
| --- | --- |
| 活動期間 | **2026/11/3～11/30** 註冊 |
| 獎勵 | 推薦人與被推薦人**各 6,000 Virgin Points** |
| 發放條件 | 被推薦人加入後 **18 個月內**，第一次從符合資格的累積交易拿到 Virgin Points |
| 推薦上限 | 推薦人每 **12 個月**最多拿 **10 次**推薦獎勵 |
| 資格 | 官方條款寫明限 **18 歲以上英國居民** |

## 三、註冊與完成交易

| 步驟 | 做法 |
| --- | --- |
| 1. 電話 | 需要**英國或美國電話**才能註冊；有美國電話的人沒問題，沒有的話可以用易博通 |
| 2. 地址 | 填寫**英國地址** |
| 3. 下載 App | App Store 轉到**英國區**才能下載 |
| 4. 完成交易 | 下載 **Virgin Trains Ticket** App 登入帳號，買一張最便宜的車票，大約 **1 英鎊** |
| 5. 等入帳 | 完成後等點數入帳 |

- **期限不急：** 註冊後 18 個月內完成交易都可以，但建議盡快做完。

## 四、加碼：綁定 Tesco 再拿 2,500 點

| 項目 | 內容 |
| --- | --- |
| 做法 | 在 Virgin Red App 搜尋 **TESCO**，連結過去綁定 Tesco 會員 |
| 獎勵 | **2,500 Virgin Points** |
| 注意 | 從 Virgin Red 連到 Tesco 需要 **VPN**；活動期間內需累積 **250 點**才符合資格，可以先綁定，之後有機會再完成 |

**合計：** 6,000＋2,500＝**8,500 點**。

## 五、6,000 點可以換什麼？

| 點數 | 可以換 |
| --- | --- |
| 6,000 點 | **華航飛上海單程經濟艙** |
| 7,000 點 | 再加 1,000 點就能換**韓國**單程（華航或大韓航空） |

維珍點數兌換華航等夥伴的方法，可以參考[維珍航空哩程教學](https://www.scottt.org/virgin-atlantic/)；Amex 轉維珍 Flying Club 加贈 30% 到 11/30，可以參考[Amex 轉維珍加贈 30%](/amex-virgin-united-marriott-transfer-bonus-november-2026)。

## 六、總結

**Virgin Red 11/30 前透過推薦連結新註冊，18 個月內完成第一筆交易，雙方各得 6,000 點；再綁定 Tesco 多拿 2,500 點，合計 8,500 點，光是 6,000 點就夠換華航飛上海單程經濟艙。** 沒註冊過 Virgin Red 的人可以把握，推薦連結：[Virgin Red 推薦註冊](https://virginred.mention-me.com/m/ol/rq2rymhn-lite-teng)。
