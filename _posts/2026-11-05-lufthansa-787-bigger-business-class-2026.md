# 漢莎 787 要加大商務艙！還有 26 架 787 待交機，正和波音洽談；現有 Allegris 商務艙 28 席還有 3 席等 FAA 認證

**新聞分類：航空資訊／星空聯盟**
**發布日期：2026 年 11 月 5 日**

**漢莎航空**準備讓未來交機的 **787-9 配置更大的商務艙**。漢莎集團執行長 **Carsten Spohr** 在 11 月 3 日的財報記者會上表示，正和波音進行**進階討論**，因為商務艙和豪華經濟艙需求強勁，787 現有的商務艙常常不夠賣。

## 一、為什麼要改

| 原因 | 內容 |
| --- | --- |
| 需求 | 商務艙、豪華經濟艙需求持續強勁 |
| 機型錯配 | 787-9 常被派去飛**原本規劃給 A350-1000、777-9** 的航線 |
| 結果 | 787 的商務艙座位數**常常少於能賣出的數量** |
| A350-1000 | 商務艙 **49 席**，交機後可補上部分運能 |

## 二、可能的改法

| 方案 | 內容 | 難度 |
| --- | --- | --- |
| 加大商務艙 | 部分新 787-9 交機時就配置更多商務艙座位 | 較複雜，已和波音進階討論 |
| 增加豪華經濟艙 | 拿掉部分經濟艙排數，改成豪華經濟艙 | 較容易；豪經表現很好 |

漢莎沒有說明會有幾架改配置、商務艙會增加多少席。

## 三、漢莎 787-9 現況

| 項目 | 內容 |
| --- | --- |
| 待交機 | **26 架**（9 月底 27 架，10 月交 1 架） |
| Allegris 配置 | 商務艙 **28**、豪華經濟艙 **28**、經濟艙 **231** |
| Allegris 商務艙 | 28 席中 **25 席**已開放，**3 席**還在等 **FAA 認證**，目標 2026 年底前 |
| 原海南航空 787 | 3 架，商務 26／豪經 21／經濟 247，將轉給**奧地利航空** |

漢莎 A350-1000 飛東京羽田的消息，可以看[漢莎 A350-1000 飛東京羽田](/lufthansa-a350-1000-tokyo-haneda)。

## 四、對旅客的影響

- 未來漢莎 787 航線的**商務艙座位會變多**，用哩程換位子的機會可能增加。
- 豪華經濟艙比例提高，經濟艙座位可能減少。
- Allegris 商務艙剩下的 3 席年底前認證後，787 商務艙才算全部開放。

## 五、總結

**漢莎正和波音討論讓部分新 787-9 加大商務艙，也考慮增加豪華經濟艙；集團還有 26 架 787-9 待交機，現有 Allegris 787 商務艙還有 3 席等 FAA 認證。** 商務艙需求強勁，各家航空都在往「高端座位變多」的方向走。
