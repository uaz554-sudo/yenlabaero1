# 【更新】美國停飛第二天：兩天取消逾 1.4 萬班！原因是承包商換光纖時路由器暴衝，FAA 估 11/15 晚上恢復、川普政府要 500 億美元

**新聞分類：航空資訊／無聯盟**
**發布日期：2026 年 11 月 15 日**

美國聯邦航空總署（FAA）**11 月 13 日**下令全國停飛後，餘波延續到週末。**11 月 14 日全美再取消逾 5,300 班**，兩天合計**超過 1.4 萬班**。原因也比較清楚了：**承包商在偏遠站點把銅纜換成光纖時，一台路由器發出大量連線請求**，拖垮多個航路管制中心的通訊。FAA 預計美東時間 **11 月 15 日晚上**（台灣 11/16 上午）恢復正常班表。

第一天的經過可以看 [美國 FAA 全國停飛 4 小時](/faa-nationwide-ground-stop-november-2026)。

## 一、兩天影響規模

| 日期（美東） | 取消 | 延誤 |
| --- | --- | --- |
| 11/13（週五，停飛當天） | 約 **9,200 班** | 約 7,500 班 |
| 11/14（週六，下午 4 點統計） | 逾 **5,300 班** | 近 6,300 班 |
| 11/15（週日） | 週六下午已預先取消約 **200 班** | － |
| **兩天合計** | **逾 1.4 萬班** | 近 1.4 萬班 |

_統計來自航班追蹤網站 FlightAware，各家媒體統計時間不同，數字略有出入。_

| 停飛當下 | 數字 |
| --- | --- |
| 下午 4 點後原定從美國機場起飛的航班 | 約 **1.1 萬班**，約 **150 萬名旅客** |
| 改變航路 | 約 600 班 |
| 轉降其他機場 | **104 班** |
| 停飛時在空中的飛機 | 約 **3,500 架**，全數安全降落 |

## 二、各航空週六受影響程度

| 航空公司 | 11/14 取消比例 | 11/15 預先取消 |
| --- | --- | --- |
| **捷藍航空** | 接近 **45%** | 33 班 |
| 達美航空 | 約 25% | 子公司 Endeavor Air 22 班 |
| 聯合航空 | 約 25% | **48 班**（最多） |
| 美國航空 | 約 25% | 20 班 |

FAA 署長貝德福德（Bryan Bedford）原本預估週六 4.1 萬個航班中會取消 4,000～5,000 班，實際超過 5,000 班。飛機和機組人員都不在原本的位置，加上不少組員已達**法定執勤時數上限**，即使停飛令解除也無法馬上恢復。

## 三、原因：承包商換光纖時路由器出問題

| 項目 | 內容 |
| --- | --- |
| 施工單位 | FAA 的航空國防承包商 **L3Harris** |
| 工程內容 | 在一處**偏遠站點**做維護，把**老舊銅纜換成光纖** |
| 出了什麼事 | 一台新路由器**每 4～5 秒對多個網路設施發出超過 1,000 次連線請求** |
| 影響 | 航管與飛機間的通訊、部分**雷達資料傳輸**不穩定，資料湧入其他通訊中心造成過載 |
| 受影響範圍 | 全美 22 個航路管制中心中有 **17 個** |
| 為什麼停飛 | FAA 擔心管制中心可能**完全失去通訊**，預防性停飛；實際上沒有任何中心完全失能 |
| 責任 | 仍在調查是**安裝失誤**還是**路由器本身有缺陷**；L3Harris 表示全力配合 |
| 網路攻擊？ | 國土安全部長與交通部長都表示**不是網路攻擊**，也沒有外國勢力介入 |

交通部長杜菲（Sean Duffy）說，這次是「FAA 系統沒撐住，承包商或設備也沒撐住」。這是 **911 之後第二次全國性停飛**，也是時間最長的一次。

## 四、政府要多少錢升級空管？

| 項目 | 金額 | 約新台幣 |
| --- | --- | --- |
| 原本要求（交通部、白宮預算局） | **301 億美元** | 約 9,821 億元 |
| ・空管現代化 | 101 億美元 | 約 3,295 億元 |
| ・塔台改善或重建 | 20 億美元 | － |
| ・機場基礎設施（含 100 億美元航廈） | 180 億美元 | 約 5,873 億元 |
| **停飛後提高到** | **500 億美元** | **約 1.63 兆元** |
| 國會 2025 年 7 月已核准（5 年） | 125 億美元 | 約 4,078 億元 |

| 進度 | 內容 |
| --- | --- |
| 銅纜換光纖 | 已完成約 **68%** |
| 軟碟片 | 計畫 2028 年底前從 400 多個空管設施淘汰 |
| 民主黨議員質疑 | 125 億美元中只簽了約 **43 億美元**合約，實際支出約 10 億美元 |
| 國會 | 眾議院議長強生表態支持今年再增加經費；預計明年 1 月起由民主黨主導國會 |

_新台幣以 Mastercard 1 美元 ≈ 32.63 元換算。_

## 五、航班被取消可以拿到什麼？

| 項目 | 規定 |
| --- | --- |
| 免費改票 | 美國航空、達美、聯合、西南、阿拉斯加／夏威夷、捷藍都推出**彈性改票** |
| 退款 | 航班取消或「重大延誤」而選擇不搭，可**退回原付款方式**，不是只給抵用金 |
| 重大延誤定義 | 美國國內線晚到 **3 小時**以上、國際線 **6 小時**以上 |
| 飯店、餐食 | 屬於航空公司無法控制的因素，**航空公司通常不負擔** |
| 信用卡保險 | 部分信用卡有班機延誤、取消保障，但 FAA 停飛**不一定理賠**，收據先留著 |

## 六、要去美國的台灣旅客

- **台美直飛**航班受影響較小，但抵達後要**轉美國國內線**的人，這兩天仍可能遇到取消、客滿。
- 先在**航空公司 App** 自己改票，比在機場排隊快；看不到好的航班時多刷幾次，常會釋出座位。
- 機場周邊的**租車和飯店**很快會被訂光，需要備案就早點訂。
- 手上有哩程的人，可以先開一張獎勵票當備案，但要先確認取消規則。

## 七、總結

**美國停飛兩天合計取消逾 1.4 萬班，原因是承包商 L3Harris 換光纖時路由器暴衝，拖累 17 個航路管制中心；官方排除網路攻擊，FAA 預計美東 11/15 晚上恢復正常。** 這次事件讓空管老舊問題再度浮上檯面，政府把升級經費要求拉高到 500 億美元，國會怎麼回應值得關注。
