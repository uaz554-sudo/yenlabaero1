# 西南航空點數兌換最高 75 折！美國時間 11/9 前訂、搭到 2027/3/10，已訂的機票也能退點重訂

**新聞分類：哩程資訊／無聯盟**
**發布日期：2026 年 11 月 8 日**

**西南航空 Rapid Rewards** 推出點數兌換促銷：**最高 75 折**，**美國時間 11/9 前訂位**、**2027/3/10 前搭乘**，美國國內線和國際線都適用，**不用折扣碼**。已經用點數訂好機票的人，也可以檢查看看能不能退點重訂。

## 一、活動規則

| 項目 | 內容 |
| --- | --- |
| 折扣 | 點數兌換**最高 75 折**（少 25%） |
| 訂位期間 | 美國時間 **2026/11/6～11/9** |
| 搭乘期間 | **2026/11/6～2027/3/10** |
| 適用航線 | 美國國內線、國際線 |
| 不適用 | **夏威夷島際航線** |
| 使用方式 | 不用折扣碼，打折航班會顯示**劃線原價**，下面是折扣後點數 |
| 稅費 | 每段單程政府規費 **5.60 美元**起，另付 |

- **「最高」75 折：** 不是每條航線、每天都有打折，熱門日期的折扣位可能很少。
- **單程、來回都適用**，所有票種都可以。

## 二、黑名單日

| 航段 | 不適用日期 |
| --- | --- |
| 美國本土國內線 | 11/28、11/29、12/26～12/28、1/2、1/3 |
| 美國本土 → 國際線、夏威夷、聖湯瑪斯、聖胡安 | 11/20～11/25、12/17～2027/1/5 |
| 國際線、夏威夷、聖湯瑪斯、聖胡安 → 美國本土 | 11/27～12/1、12/17～2027/1/5 |

## 三、已經訂好的票怎麼辦？

西南航空用點數訂的機票可以**免費取消、點數退回**。如果你已經用點數訂了這段期間的航班，現在查詢發現變便宜，就可以：

1. 取消原本的訂位，點數退回帳戶。
2. 馬上用折扣後的點數重新訂同一班。

## 四、適合誰？

- **有 Rapid Rewards 點數**、近期要在美國國內飛的人，特別是感恩節後到 3 月初。
- **Chase 卡友：** Ultimate Rewards 點數可以 1:1 轉到西南航空，有需要再轉。
- **台灣讀者：** 西南航空 2027 年春天起會和華航合作，Rapid Rewards 點數可以兌換華航航班，可以參考[西南航空哩程計畫 2027 大改](/southwest-rapid-rewards-2027-changes)；這次的 75 折只適用西南自家航班。

## 五、總結

**西南航空點數兌換最高 75 折，美國時間 11/9 前訂、2027/3/10 前飛，國內線、國際線都適用，不用折扣碼；已訂好的票可以免費退點再用折扣價重訂。** 折扣位有限，要訂的人越早越好。
