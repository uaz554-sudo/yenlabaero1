# 倫敦瑰麗酒店易主！美國 Gencom 收購 308 間房的 Rosewood London，鄭家第二度求售後成交，傳價約 3 億英鎊

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 4 日**

**倫敦瑰麗酒店（Rosewood London）**換了新主人：美國投資公司 **Gencom** 宣布收購這間 **308 間房**的奢華飯店，交易金額未公開。這是 Gencom **第一次進軍歐洲奢華飯店市場**，賣方是持有瑰麗酒店集團的香港**鄭家**。

## 一、交易重點

| 項目 | 內容 |
| --- | --- |
| 買方 | **Gencom**（美國私募投資公司） |
| 共同投資 | White Bridge Capital |
| 融資銀行 | **滙豐、桑坦德銀行（Santander）** |
| 價格 | **未公開**；洽談階段曾傳出約 **3 億英鎊**（約 4.06 億美元） |
| 賣方 | 香港鄭家家族辦公室 |
| 背景 | 鄭家旗下新世界發展面臨資金壓力；這是十年內**第二度**求售 |
| 意義 | Gencom 首度進軍歐洲奢華飯店 |

Gencom 創辦人 Karim Alibhai 形容這是「**具代表性、無可取代的資產**」。報導沒有提到更換品牌或管理公司。

## 二、倫敦瑰麗酒店

| 項目 | 內容 |
| --- | --- |
| 位置 | 倫敦 **Holborn** 區 |
| 建築 | 英國**二級保護建築**（Grade II listed）；前身為 Chancery Court 飯店 |
| 房間數 | **308 間**：264 間客房＋44 間套房 |
| 餐飲 | 3 間餐廳與酒吧 |
| 設施 | SPA |
| 特色 | 全世界唯一**有自己郵遞區號**的套房 |
| 集團規模 | 瑰麗全球 42 間飯店之一 |
| 倫敦姊妹館 | The Chancery Rosewood，2025 年 9 月在前美國大使館開幕 |

The Chancery Rosewood 也是這次瑰麗 Rosewood Beyond 7 折促銷排除的飯店之一，詳見[瑰麗 Rosewood Beyond 年度最大優惠](/rosewood-beyond-sale-30-off-2026)。

## 三、對旅客的影響

| 項目 | 說明 |
| --- | --- |
| 現有訂房 | 業主變更一般不影響已訂房間 |
| 品牌 | 目前沒有更換品牌的消息，仍以 Rosewood London 營運 |
| 訂房管道 | Rosewood Elite 顧問、官網等照舊 |

## 四、總結

**美國 Gencom 收購 308 間房的倫敦瑰麗酒店，價格未公開（洽談時傳約 3 億英鎊），由滙豐與桑坦德融資，是 Gencom 首次進軍歐洲奢華飯店；賣方香港鄭家十年內第二度求售後成交。** 對住客來說，短期內飯店仍以瑰麗品牌營運。
