# Andaz 黃金海岸開幕！凱悅 Andaz 首度進軍澳洲，202 間房、免費迷你吧，開幕價凱悅會員 75 折

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 20 日**

凱悅的生活風格品牌 **Andaz** 11 月 16 日在**澳洲黃金海岸**開幕，是 Andaz 在**澳洲和太平洋地區的第一間**。飯店比原定的 2025 年中晚了一年多開幕。

## 一、飯店基本資料

| 項目 | 內容 |
| --- | --- |
| 名稱 | **Andaz Gold Coast** |
| 開幕 | **2026/11/16** |
| 位置 | 黃金海岸 **Broadbeach**，The Star Gold Coast 綜合度假娛樂區**二號塔** |
| 客房 | **202 間**客房與套房 |
| 餐飲 | 4 個餐飲空間，含泳池俱樂部 |
| 建築 | DBI Architects；室內設計 Hachem |
| 房價 | 每晚 **350 澳幣**起（約 235 美元，約 **NT$7,668**） |

台幣依 2026/11/17 Mastercard 美元匯率換算。

![Andaz 黃金海岸客房](/assets/images/andaz-gold-coast-guest-room.jpg)
_Andaz 黃金海岸客房，落地窗看 Broadbeach 海岸大樓（照片：Hyatt）_

## 二、客房

| 項目 | 內容 |
| --- | --- |
| 窗景 | 落地窗 |
| 迷你吧 | **免費**，有在地手作零食 |
| 備品 | **Byredo** |
| 吹風機 | **Dyson** |
| Signature Floor | **8 樓**，每間都有**私人露台** |
| Andaz Residence Suite | 室內 132 平方公尺＋49 平方公尺露台，有完整廚房、按摩浴缸 |

## 三、餐飲與設施

| 名稱 | 內容 |
| --- | --- |
| **Nove Restaurant and Bar** | 招牌餐廳，石窯柴火料理，義大利、西班牙、法國海岸風味 |
| Vista Lounge | 早餐到晚上輕食，有在地烘焙 |
| Verde Bar | 綠色調酒吧，週五、六晚上黑膠 DJ |
| **Andaz Pool Club** | 黎凡特風味餐點、私人小屋，**外客也能去** |
| Golden Hour | 房客每天在 Vista Lounge 享免費葡萄酒、啤酒、飲料和小點 |
| Andaz Alive | 池畔皮拉提斯、呼吸練習、冥想 |

早餐可以點最多 3 道現做小盤，加上麵包和咖啡。

## 四、設計與藝術

| 項目 | 內容 |
| --- | --- |
| 設計概念 | 「Chase the Sun」，從海岸到山區的光線變化 |
| 大廳 | 水晶球組成的天花板裝置 |
| 藝術 | 13 件澳洲原創作品，6 件在公共空間、7 件在客房 |
| 代表作 | 昆士蘭原住民藝術家 Judy Watson 的大型混合媒材畫作 |
| 制服 | 澳洲設計師 Kit Willow 與 Melinda Looi 合作 |

## 五、開幕優惠

| 項目 | 內容 |
| --- | --- |

| 會員權益 | 合格住宿適用凱悅會員權益 |

**Andaz 黃金海岸 11/16 開幕，是 Andaz 在澳洲第一間：202 間房、免費迷你吧、8 樓每間有露台，房價 350 澳幣起。** 12/14～2027/6/30 入住有開幕價，凱悅會員 75 折。黃金海岸高級飯店選擇越來越多，喜歡凱悅的人多了一個選擇。
