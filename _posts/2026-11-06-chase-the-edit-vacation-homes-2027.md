# Chase The Edit 2027 年加入 1 萬間度假屋！Sapphire Reserve 每次 250 美元額度可用，再送 150 美元住宿額度

**新聞分類：信用卡／美國信用卡**
**發布日期：2026 年 11 月 6 日**

**Chase Travel** 的精選飯店計畫 **The Edit** 要加入度假屋了：**2027/1/1** 起新增超過 **1 萬間**度假屋，由英國度假屋平台 **Plum Guide** 挑選。**Sapphire Reserve** 等高階卡友可以把每次最高 **250 美元**的 The Edit 額度用在度假屋上，另外再拿 **150 美元**住宿期間額度。

## 一、重點整理

| 項目 | 內容 |
| --- | --- |
| 開始日期 | **2027/1/1** |
| 數量 | 超過 **10,000 間**，全球 |
| 挑選 | **Plum Guide**，依舒適度、設計、地點挑選 |
| 適用卡 | **Sapphire Reserve**、**Sapphire Reserve for Business**、**J.P. Morgan Reserve** |
| The Edit 額度 | 可用，**每次付費住宿最高 250 美元**（約新台幣 8,157 元） |
| 住宿期間額度 | **150 美元**（約新台幣 4,894 元），可用在機場接送、冰箱備品、按摩、私廚等 |
| Points Boost | **不適用**，度假屋不能用點數加成兌換 |

_匯率：1 美元＝32.6279 元新台幣（Mastercard，2026/11/2）。_

## 二、各卡 The Edit 年度額度

| 卡片 | 年度額度 |
| --- | --- |
| Sapphire Reserve | 最高 **500 美元**（每次最高 250 美元） |
| J.P. Morgan Reserve | 最高 **500 美元**（每次最高 250 美元） |
| Sapphire Reserve for Business | 2027/1/1 起提高到 **1,000 美元** |

## 三、為什麼要加度假屋？

- **團體旅行變多：** 朋友、家人想住在同一個屋簷下，而不是分開訂好幾間飯店房。
- **年輕族群有興趣：** Chase Travel 調查超過 4,000 名美國人，**74%** 的 Z 世代與千禧世代有興趣未來訂度假屋。

## 四、對卡友的影響

- **額度更好用：** 以前 The Edit 只有飯店，額度一定要用在精選飯店；2027 年起多了度假屋可以選。
- **注意 Points Boost 不適用：** 想用 Chase 點數加成兌換的人，度假屋不在範圍內，用點數訂比較不划算。
- Chase Travel 年底前還有指定卡友刷 600 美元回饋 100 美元的活動，可以參考[Chase Travel 回饋 100 美元](/chase-travel-100-delta-amex-offers-november-2026)。

## 五、總結

**Chase The Edit 2027/1/1 起加入超過 1 萬間 Plum Guide 精選度假屋，Sapphire Reserve、Reserve for Business、J.P. Morgan Reserve 卡友可用每次最高 250 美元的額度，再送 150 美元住宿期間額度，但不適用 Points Boost。** 適合家庭、朋友一起出遊，想把 The Edit 額度用掉的卡友。
