# Aeroplan 點數 11/30 起恢復過期！18 個月沒有活動就會失效，用買點、轉點或凱悅住宿就能延長

**新聞分類：哩程資訊／星空聯盟**
**發布日期：2026 年 11 月 26 日**

**加拿大航空 Aeroplan** 暫停多年的**點數過期**規定，**2026 年 11 月 30 日起恢復**。帳戶如果 **18 個月**都沒有符合資格的活動，點數就會過期。很多人放著不管的 Aeroplan 點數，要注意了。

## 一、規則

| 項目 | 內容 |
| --- | --- |
| 恢復日期 | **2026/11/30** 起過期，12/1 起正式回到原規定 |
| 過期條件 | **18 個月**沒有符合資格的帳戶活動 |
| 重新計算 | 每做一次活動，18 個月重新起算 |

## 二、哪些算「活動」？

| 活動 | 算不算 |
| --- | --- |
| 累積點數 | ✅ |
| 兌換點數 | ✅ |
| 捐贈點數 | ✅ |
| 轉入點數（例如信用卡點數） | ✅ |
| 轉換點數 | ✅ |
| 凱悅住宿累積的 Aeroplan 點數 | ✅ |

## 三、怎麼查自己的帳戶？

1. 登入 Aeroplan 帳戶，點右上角名字 →「Go to My Dashboard」。
2. 點「Activity」。
3. 用「Filters」選最近 **2 年**的紀錄。

最近 18 個月內有任何一筆符合資格的活動，點數就不會過期。

## 四、怎麼延長？

| 方法 | 說明 |
| --- | --- |
| 買點數 | 買一點點就算活動；Aeroplan 買點最高加贈 **100%**，到 **12/10** |
| 轉入 | 從信用卡點數轉入少量 |
| 搭機 | 搭加航或星空聯盟夥伴累積 Aeroplan |
| 飯店 | 凱悅住宿選擇累積 Aeroplan |

## 五、總結

**Aeroplan 點數 11/30 起恢復過期，18 個月沒有累積、兌換、轉入等活動就會失效。** 先登入查最近的活動紀錄，快到 18 個月的話，買一點點或轉一點點就能重新計算。
