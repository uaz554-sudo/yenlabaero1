# 雅高 ALL 預告：12/6～12/20 訂房、住到 2027/1/22，指定會員住一晚就送 5,000 點（約 100 歐元）

**新聞分類：飯店資訊／集團體系**
**發布日期：2026 年 11 月 23 日**

**雅高 ALL** 即將推出一個很划算的活動：**指定會員**在 **12 月 6 日到 20 日**訂房、住到 **2027 年 1 月 22 日**，完成一次住宿就送 **5,000 點**，約值 **100 歐元**。

## 一、活動重點

| 項目 | 內容 |
| --- | --- |
| 對象 | **受邀或登記成功**的 ALL 會員 |
| 訂房 | **2026/12/6～12/20** |
| 入住 | **2026/12/6～2027/1/22** |
| 加送 | **5,000 點** ALL 點數 |
| 價值 | 約 **100 歐元**（每點 0.02 歐元） |
| 最少晚數 | **沒有** |
| 管道 | ALL 官網或 ALL Accor App 直訂 |
| 名額 | 全球最多 **10,000 次**成功住宿 |
| 疊加 | 可搭配會員價，最多 9 折 |

## 二、划不划算？

| 情況 | 說明 |
| --- | --- |
| 訂一晚便宜的雅高飯店 | 住一晚送 100 歐元點數，可能比房價還高 |
| 年底本來就要住雅高 | 直接多拿 100 歐元 |
| 台灣讀者 | 台灣目前沒有雅高飯店，可用在日本、香港、東南亞 |

**例子：** 訂一晚價格不高的雅高飯店，拿到的 5,000 點約 100 歐元，可以折抵下一次住宿。

## 三、還不確定的地方

| 項目 | 狀態 |
| --- | --- |
| 選會員的標準 | 還不清楚 |
| 一般會員能否登記 | 還不清楚 |
| 正式細則 | 12/6 上線時公布 |

活動 12/6 正式上線，到時記得登入 ALL 帳戶看有沒有登記入口。雅高其他規則變化可以參考[雅高 Accor+ Explorer 送禮 75 折](/accor-plus-explorer-gift-25-off-2026)。

## 四、總結

**雅高 ALL 指定會員 12/6～12/20 訂房、住到 2027/1/22，完成一次住宿送 5,000 點（約 100 歐元），沒有最少晚數。** 全球限 10,000 次，12/6 上線後記得登入確認有沒有資格。
