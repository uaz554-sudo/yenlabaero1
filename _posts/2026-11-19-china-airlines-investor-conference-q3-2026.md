# 華航法說會重點：前三季賺 126 億、寒假春節機位已賣八成，桃機第三航廈搶下最大貴賓室

**新聞分類：航空資訊／天合聯盟**
**發布日期：2026 年 11 月 19 日**

**中華航空** 11 月 18 日舉行線上法說會，公布 2026 年前三季成績。燃油價格比去年同期大漲近六成，華航靠**客運、貨運價量齊揚**撐住獲利。對旅客來說，最值得注意的是：**2027 年寒假和春節機位已經賣掉八成**，以及**桃園機場第三航廈**啟用後的安排。

## 一、前三季財報

| 項目 | 2026 年前三季 | 年增減 |
| --- | --- | --- |
| 合併營收 | **1,859.4 億元** | **+20.0%** |
| 營業淨利 | 157.7 億元 | +0.1% |
| 本期淨利 | **126.2 億元** | +3.0% |
| 歸屬母公司淨利 | 110.0 億元 | 持平 |
| 每股盈餘 | 1.80 元 | 去年同期 1.81 元 |
| 每股淨值（9 月底） | 17.02 元 | － |
| 負債比率 | 約 72% | － |

## 二、客運：載客率 82.9%，商務艙收入成長 16%

| 項目 | 數字 | 年增減 |
| --- | --- | --- |
| 客運收入 | 875.4 億元 | +12.6% |
| 載客人數 | 909.1 萬人次 | +5.1% |
| 運能 | 352.3 億延人公里 | −1.0% |
| 平均載客率 | **82.9%** | +5.0 個百分點 |
| 單位收益 | 3.00 元 | +6.8% |
| 高艙等收入 | **223 億元** | +16%，占客運 32% |
| 附加收入（前 9 月） | 約 21 億元 | +9% |

附加收入裡，**選位費占 57.8%** 最多，其次是改票手續費 24.0%、超額行李 13.4%。

**客運收入來源：**

| 區域 | 占比 |
| --- | --- |
| 東北亞 | 29% |
| 北美 | 21% |
| 東南亞 | 18% |
| 歐洲 | 14% |
| 中國 | 8% |
| 大洋洲 | 7% |
| 香港 | 2% |

## 三、貨運：單位收益創 2023 年以來新高

| 項目 | 數字 | 年增減 |
| --- | --- | --- |
| 貨運收入 | **628 億元** | **+29.3%** |
| 平均載貨率 | 68.8% | +2.2 個百分點 |
| 單位收益 | 14.34 元 | **+23.9%** |
| 北美占貨運收入 | 62% | － |

AI 伺服器、半導體等科技產品出貨是主要動能。

## 四、燃油成本占營業成本 38%

| 項目 | 數字 |
| --- | --- |
| 燃油均價（新加坡航油） | 每桶 **135.8 美元**，年增 58.1% |
| 用油量 | 1,224.2 萬桶，年增 1.5% |
| 燃油成本 | **570.8 億元**，年增 59.3% |
| 占營業成本 | 從 30% 升到 **38%** |

過去油價在 135 美元以上，華航容易虧損。這次能賺錢，是因為客運載客率、單位收益和高艙等收入都提高，貨運價格也大漲，再加上換用 A321neo、777 貨機等較省油的機型。

## 五、旅客最關心的三件事

### 1. 2027 寒假、春節機位已賣八成

| 項目 | 內容 |
| --- | --- |
| 銷售進度 | 全線機位已賣 **八成** |
| 最熱市場 | **日本、韓國** |
| 票價 | 大陸、歐洲、東北亞熱門航班，**有機會比 2026 年同期還高** |

過年要出國還沒買票的人，最好盡快訂。

### 2. 桃機第三航廈：雙航廈營運、最大貴賓室

| 項目 | 內容 |
| --- | --- |
| 北廊廳 | 2025 年底已啟用 |
| 主航廈 | 進行室內裝修，預計 **2027 年底**啟用 |
| 南廊廳 | 時程以桃機公告為準 |
| 華航安排 | **第二、第三航廈雙航廈營運** |
| 第三航廈優先航線 | **北美、東南亞、東北亞** |
| 貴賓室 | 已爭取第三航廈**最大面積**貴賓室 |

華航會把主力轉機航線集中在第三航廈，方便東南亞旅客經桃園轉機到北美，也會調整報到、行李轉運和跨航廈轉機動線。

### 3. 今年新開與增班的航線

| 航線 | 內容 |
| --- | --- |
| 台中－沖繩 | 7/21 起每天飛 |
| 桃園－富山 | 8/20 起每週 2 班 |
| 高雄－高松 | 9/17 起每週 3 班 |
| 桃園－札幌 | 12/16～2027/3/27 每天加 1 班 |
| 大洋洲 | 10/25 起每週共 23 班 |

此外，國際線酬賓機票 9/16 起改成三段式動態兌換；華夏會員和**西南航空、捷藍航空**的雙向合作，可以接到美國內陸 100 多個航點。

## 六、機隊規劃

| A330-300 | 12 架 | 2028 年前全部退役 |

| 777-9 | － | 15 架 |
| A350-1000 | － | 15 架 |

客機現有 **68 架**，中長期規劃 **84 架**新世代客機。

## 七、2027 年展望

- **客運：** 需求仍有韌性，但各區域單位收益可能分化，目標是單位收益整體持平。北美靠新機強化和聯合航空的合作，大洋洲增班、換大飛機，東北亞開拓二線城市。
- **貨運：** AI 伺服器、半導體持續帶動，運價預期維持在相對高檔。

## 八、總結

**華航前三季營收 1,859.4 億元、淨利 126.2 億元，高油價下仍維持獲利。** 對旅客最實際的是：**2027 寒假、春節機位已賣八成，日韓最熱**，熱門航線票價可能比今年高；桃機第三航廈 2027 年底主航廈啟用後，華航會把北美、東南亞、東北亞航線放進去，並拿到**最大面積的貴賓室**。
