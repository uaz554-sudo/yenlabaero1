# 花旗頂級邀請制 Citi ULTIMA 升級 World Legend Mastercard！香港、新加坡推出，帶 3 位同行走機場快速通關

**新聞分類：信用卡／無聯盟**
**發布日期：2026 年 11 月 16 日**

**花旗**與 **Mastercard** 宣布在**香港**、**新加坡**推出 **Citi ULTIMA World Legend Mastercard**。Citi ULTIMA 是花旗給**超高淨值客戶**的邀請制財富管理服務，這次信用卡從 World Elite 升級到 Mastercard **最高等級的 World Legend**。花旗先前已在美國推出全球第一張 World Legend 卡，這次擴展到亞洲兩大財富管理中心。

## 一、基本資料

| 項目 | 內容 |
| --- | --- |
| 卡片 | Citi ULTIMA World Legend Mastercard |
| 推出市場 | **香港、新加坡** |
| 申請方式 | **邀請制**，洽花旗客戶經理 |
| 對象 | 花旗超高淨值客戶 |
| 現有卡友 | 香港 Citi ULTIMA 持卡人已**自動從 World Elite 升級**到 World Legend |
| 卡組織等級 | Mastercard 個人卡最高等級 |

## 二、新增的 World Legend 禮遇

| 禮遇 | 內容 |
| --- | --- |
| **Mastercard Fast Track** | 指定機場**安檢快速通道**，持卡人＋最多 **3 位**同行，視供應情況 |
| **Taste by Priceless** | Mastercard 機場餐飲會所，**香港機場**（2026 年 8 月開幕）、**聖保羅瓜魯柳斯機場**，持卡人＋最多 3 位同行 |
| **The Mastercard Collection** | 亞太 **15 個市場、650 間**餐廳禮遇，**2027/2/1** 起增加到 **1,300 間以上**；另有娛樂、旅遊禮遇 |
| **Priceless Experiences** | 受邀參加私人、文化與生活品味活動 |

## 三、Citi ULTIMA 原有禮遇

| 類別 | 內容 |
| --- | --- |
| 禮賓 | 專屬 ULTIMA 客戶經理、個人化生活規劃、禮賓與優先支援 |
| 飯店 | 全球 **800 間**豪華飯店，連住 **2 晚以上送 1 晚** |
| 機票 | 指定航空公司**同行機票**禮遇 |
| 餐廳 | 香港米其林星級餐廳優先訂位、新加坡主廚精選餐飲 |
| 每季餐飲折扣 | 單筆滿港幣 3,750 折 1,500，或滿 2,500 折 750 |
| 指定餐廳 | 全年 **9～85 折**（10%～15% 優惠） |
| 其他 | 全球高爾夫球會、香港私人會所禮遇 |

| 港幣 | 約新台幣 |
| --- | --- |
| 3,750 | 15,757 元 |
| 1,500 | 6,303 元 |
| 2,500 | 10,505 元 |
| 750 | 3,151 元 |

_以 Mastercard 1 港幣 ≈ 4.20 元換算。禮遇、資格與供應情況依市場不同。_

## 四、Mastercard 個人卡等級

| 等級 | 定位 |
| --- | --- |
| **World Legend** | **最高等級**，花旗已在美國、香港、新加坡發行 |
| World Elite | 頂級卡，原本 Citi ULTIMA 的等級 |
| World | 高階卡 |
| 白金、鈦金等 | 一般等級 |

## 五、台灣讀者能辦嗎？

- 花旗在台灣的個人金融業務已經轉給**星展銀行**，台灣**沒有**發行花旗信用卡。
- Citi ULTIMA 是**香港、新加坡**當地的邀請制服務，要在當地是花旗超高淨值客戶才有機會受邀。
- 常經過**香港機場**的人可以留意：Taste by Priceless 餐飲會所開放給合資格的 World Legend 持卡人，**不限發卡地區**。

## 六、總結

**花旗在香港、新加坡推出 Citi ULTIMA World Legend Mastercard，新增機場安檢快速通道、Taste by Priceless 機場餐飲、亞太 650 間餐廳禮遇，現有香港卡友自動升級。** 這是邀請制的超高端卡，台灣讀者無法申請，但可以看出頂級信用卡正往機場體驗、餐飲禮遇發展。
